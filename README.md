# 小兔学习乐园

面向小学生的中文网页应用，包含语文、数学、英语三个学科入口。语文提供拼音学习、第一阶段六个字词基础主题、第二阶段五个句子主题及第三阶段的字词进阶、阅读与积累；数学提供第一阶段“数与运算”的五个主题；英语提供自然拼读、单词点读、拼写练习和故事共读。

采用原生 JavaScript、CSS、SVG 和 Vite，无后端、无登录。学习记录保存在当前浏览器的 localStorage 中，页面不请求外部字体、追踪服务或在线语音接口。

## 统一 UI 与样式规范

**后续所有功能开发、学科扩展和页面调整，必须遵循 [UI 与样式规范](docs/UI与样式规范.md)，优先复用公共组件与样式，不再为各学科复制一套按钮、卡片、选项或响应式规则。**

该文档集中维护导航、布局断点、字号、配色、学习卡、按钮、答题反馈、拼音辅助、无障碍与验收要求。公共视觉令牌和组件样式维护在 `src/ui-theme.css`；需要调整统一规则时，同步修改规范、公共实现及回归测试。各主题实现与验收文档中的旧版截图和数值仅作历史记录，不作为新功能的样式依据。

## 本机数据导入与导出

在“学习设置 → 本机数据备份”中导出完整 JSON 备份，或选择备份文件导入。备份包括全部配置、昵称、语文/数学/英语学习进度、错题、收藏、练习历史、草稿，以及星星、奖励、达标记录和展示选择。导入需再次确认，会替换而非合并当前数据；建议先导出当前记录。文件只在本机处理，不上传。

备份使用独立的格式版本号，并记录导出它的应用版本，供排查问题使用；导入兼容性由备份格式与数据结构版本决定，不比较应用版本高低。旧备份缺少的新字段自动补默认值，不支持的版本或损坏文件在写入前拒绝。后续数据结构升级必须保留旧备份迁移和历史样本测试，详见 [本机数据备份与兼容约定](docs/本机数据备份与兼容约定.md)。

## 长期架构与功能边界

以下为全项目的长期约束，适用于所有学科、现有功能和后续新增功能；后续设计与实现均须遵守。

- **保持纯前端静态应用，不引入后端或云端业务方案。** 教学交互和学习数据处理在用户设备、浏览器内完成，不增加后端 API、云端数据库、云同步或在线语音识别、合成、评分服务。课程文字、图片和示范音频随静态站点提供；静态文件托管不改变这一约束。
- **所有学科及新增模块统一存储、统一备份。** 配置、学习记录和奖励等本机持久化信息统一纳入应用根数据对象。每个模块通过公共存储入口保存自己的字段，并随整份数据一起导入或导出。详见 [本机数据备份与兼容约定](docs/本机数据备份与兼容约定.md)。
- **以后也不加入自动背诵评分。** 不再规划背诵语音转文字、自动漏字判定、发音测评或自动背会认证。古诗学习保留示范朗读、原文与拼音、遮文背诵和自主练习。
- **学习不依赖录音设备。** 不把麦克风或录音权限作为学习、练习、进度记录和奖励的前提。保存录音目前不是已确定的开发任务；将来若单独确认增加，也只作为可选的本机录制、回听和保存工具，不转写、不评分、不上传。无麦克风、权限被拒绝或录音不可用时，仍能完整使用其他学习功能。

## 本地运行

需要 Node.js 20.19+ 或 22.12+；开发环境使用 Node.js 24。

```sh
npm install
npm run dev
```

在浏览器打开终端显示的地址，默认是 `http://127.0.0.1:5173`。

```sh
npm run build
npm run preview
```

生产文件输出到 `dist/`，可以部署到支持静态文件的网站根目录。若部署在子目录，需要同时调整 Vite 的 base 及应用内以 `/` 开头的资源路径；目前默认根目录部署。

## 公共规则

以下规则适用于后续所有学科的新增内容；已有功能逐步适配，不为了统一名称破坏现有学习记录。

- **内容统一使用“阶段 → 主题 → 小分类”三层结构。** 阶段有顺序和名称，例如“第一阶段 · 数与运算”；主题合并同类知识，例如“加减法”“除法”；小分类承载具体学习范围，例如“进位加法”“有余数的除法”。学习卡、例题和练习题属于小分类内的内容，不再增加导航层级。
- **先规划，再实现。** 每个学科维护独立的学习分类规划文档，记录阶段名称、主题顺序、小分类及实现范围。语文见 [语文学习分类规划](docs/语文学习分类规划.md)，数学见 [数学学习分类规划](docs/数学学习分类规划.md)。规划中的内容不等于已上线内容。
- **排序表示大致难度，不设前置解锁。** 允许跨阶段、跨主题、跨小分类学习与复习。古诗积累、朗读、口头表达和简单写作可以从一开始穿插进行；数学也可结合生活穿插测量、时间和图形活动。
- **导航保持一致。** 顶部分类入口组织阶段，阶段内展示主题；主题页面展示小分类。桌面主题保持一行，超出可横向滚动并通过目录搜索选择；手机使用下拉入口。仅一个阶段时可直接展示主题，在页面标题上方标明阶段。保留各自上次选择，不提前添加无内容入口。
- **UI 与样式必须复用统一规范。** 页面标题、小分类、学习卡、例题、参考思路、按钮、练习选项、反馈、结果页、成长花园、学习位置计数和响应式布局均遵循 [UI 与样式规范](docs/UI与样式规范.md)；新增学科只补充必要的教学展示，不单独改写公共组件。
- **练习与进度规则一致。** 自评认识和首次答对分别记录；答错重试不改写首次成绩，先看答案算首次跳过；错题在新一轮错题复习中首次独立答对才移出。各学科、各主题记录隔离，共享已有奖励去重规则。
- **扩课同步考虑奖励。** 新增阶段、主题、小分类或题目时，遵循 [奖励规则与扩展约定](docs/奖励规则与扩展约定.md)，同步维护主题徽章、铜银金奖牌范围及长期达标记录；新奖励回查历史补发，未获奖按当前课程范围计算，已获奖永久保留。每件物品保留一句话条件，复杂口径通过收藏总则、分类规则或物品专属问号说明，悬停摘要不超过 100 字，点击查看全文。
- **本机保存、自由练习。** 进度保存在当前浏览器，刷新后恢复；清空记录沿用二次确认，同时清除各学科进度。数学与语文主题支持每轮 10/20/30 题，题量不足时使用实际题数，新一轮优先抽取未练题。
- **实现与验证同步。** 内容标识必须稳定、唯一，答案唯一并附解释；所有小分类都应有学习内容和练习题。新增教学内容补充内容校验及关键流程浏览器测试，检查桌面、平板、手机布局；测试截图等产物不提交。

## 音频说明

### 自然拼读

自然拼读按从字母、小词到故事的路线组织，包含 12 个模块、48 课、914 个词形和 36 篇故事。可以听单词、选词义、拼字母、找规律，也可以收藏喜欢的单词，回顾需要再练的题目。

点击“听一听”播放单词；选择慢速后，可以放慢再听。听词练习先完整听一次再作答。故事可以先自己读，再听完整内容，并回答小问题。

学习位置、收藏和错题会保留，下次可以继续。英语、语文、数学的记录统一保存，各模块的进度按字段区分。“清空本机学习记录”会同时清空全部记录。更多学习建议见 `docs/英语自然拼读实施与验收.md`。

### 语文拼音

音频已经随项目放在 `public/audio/` 中，正常运行不需要重新下载。

主要来源是 [hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn)，má（二声）使用 Wikimedia Commons 收录的 Yue Tan 真人“麻”录音替换。署名及许可说明位于 [public/audio/ATTRIBUTION.md](public/audio/ATTRIBUTION.md)，原始说明保存在 [public/audio/UPSTREAM-README.md](public/audio/UPSTREAM-README.md)。文件覆盖清单位于 `public/audio/manifest.json`，替换录音的来源和重新下载规则位于 `public/audio/overrides.json`。

```sh
npm run audio:download
```

以上命令只补充缺失文件，需要访问 GitHub 的 raw 文件域名。已有本地文件会保留，下载失败记录在清单中。

教育内容有以下实际限制：

- 独立 `ong` 录音尚缺，当前明确使用 `dōng` 例音，提示孩子听后半段；不进入需要独立韵母读音的听辨题。
- 部分韵母借助同音或对应完整音节示范；声母借助教学呼读音对应的音节示范，不把它们当作短促本音。部分三拼的分解音尚未覆盖时，会提示自行拼读，答后可听完整音节。
- 13 个双字词缺少上游完整词语录音，使用已下载的音节逐字拼读；界面会作提示。轻声词均使用已有完整词语录音。
- 已核查下载来源、覆盖关系及浏览器播放；仍需普通话教师逐项试听审核，尤其是呼读音、韵母示范和语流变调。自动解码测试不能确认教学发音正确性。

### 字词进阶与古诗

第三阶段八个主题共 100 张学习卡、263 道选择题、96 个开放表达任务和 4 组句段排序。形近字提供字形、读音与词义对照；同音字、多音字结合完整句子辨析；五个阅读主题提供短文原文、阅读方法与题目依据；古诗提供 20 首原文、逐字拼音、简释、本地普通话合成示范朗读和可随时打开的遮文背诵，并穿插 10 则寓言、节日和成语俗语。

各主题和小节均可直接进入，支持 10/20/30 题、独立错题、本机进度及草稿恢复。古诗可以从一开始穿插学习；20 首诗均可常速或慢速播放、停止，换诗和离开页面会停播。朗读使用合成语音，文件随站点提供，运行时不调用在线语音服务；尚未经过普通话教师逐首试听。自动背诵评分不在当前及后续开发范围内，详细范围见 `docs/第三阶段字词与古诗实现与验收.md`。

古诗音频位于 `public/audio/poetry/`，包含原文、语音来源和 SHA256 清单。在装有 `Microsoft Huihui Desktop` 的 Windows 上，可运行 `npm run poetry:audio:generate` 离线重新生成。生成器仅为子进程设置 `RemoteSigned`，不改变系统或用户的 PowerShell 执行策略；其他系统可直接播放仓库内的 WAV。

## 验证

```sh
npm test
npm run test:browser
```

浏览器测试通过 Playwright 启动已安装的 Chrome，配置位于 `playwright.config.js`。若机器未安装 Chrome，可以安装 Playwright Chromium 并将配置中的 `channel: 'chrome'` 删除。

多工作区并行开发时，可设置 `PLAYWRIGHT_PORT` 指定独立测试端口；设置后不会复用已有服务。PowerShell 示例：`$env:PLAYWRIGHT_PORT='5186'; npm run test:browser`。若 Node 环境代理导致本地请求失败，可在测试终端设置 `$env:NODE_USE_ENV_PROXY='0'`，不必修改系统代理。

启动开发服务器后，还可验证所有录音能被浏览器解码且不是近乎静音的文件：

```sh
npm run test:audio
```

浏览器测试会在 `artifacts/` 生成电脑、平板、手机预览图。音频检查在同目录生成 JSON 报告。这些产物不加入版本控制。

新增学科内容时，先在学科规划中明确“阶段 → 主题 → 小分类”，再配置 `subjects` 的 `features`。语文主题在 `src/chinese-topics.js` 注册，数学主题在 `src/math-topics.js` 注册，均自动生成入口。各主题内容保存在对应的 `*-data.js` 文件中，进度保存在 `topics` 字段，数学使用 `math-` 前缀标识以隔离记录；语文第二阶段另使用 `src/sentence-content.js` 组织课程和表达任务。

汉字小节不设解锁条件，可与拼音、古诗积累、朗读和简单表达穿插学习。笔顺采用项目内绘制的 SVG 线条示意，支持下一笔、上一笔、任意笔跳转和从头看，不提供手写识别或书法评分。汉字进度保存在 `bunny-garden-v1` 的 `hanzi` 字段中，与拼音错题和自评记录隔离，共享星星奖励、完成历史和清空确认。具体范围见 [docs/汉字笔画与结构实现与验收.md](docs/汉字笔画与结构实现与验收.md)。

英语接入 `phonics` 页面，进度位于统一根数据 `bunny-garden-v1` 的 `phonics` 字段，与语文、数学、公共配置及奖励一起保存和备份。
