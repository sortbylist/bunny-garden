# 小兔学习乐园

面向小学生的中文网页应用，包含语文、数学、英语三个学科入口。当前完成语文学科的拼音学习、汉字笔画与结构，数学和英语展示待建设页面。

采用原生 JavaScript、CSS、SVG 和 Vite，无后端、无登录。学习记录保存在当前浏览器的 localStorage 中，页面不请求外部字体、追踪服务或在线语音接口。

## 本地运行

需要 Node.js 20.19+ 或 22.12+；开发环境使用 Node.js 24。

```sh
npm install
npm run dev
```

在浏览器打开终端显示的地址，默认是 `http://127.0.0.1:5173`。

```sh
npm run build
npm run preview
```

生产文件输出到 `dist/`，可以部署到支持静态文件的网站根目录。若部署在子目录，需要同时调整 Vite 的 base 及应用内以 `/` 开头的资源路径；目前默认根目录部署。

## 已实现

- 三学科侧栏、桌面收起与手机抽屉导航、顶部功能 tab。
- 汉字笔画与结构：8 种笔画、9 个逐笔示例、6 个偏旁部首、18 个结构例字；共 41 个学习项目、56 道练习题，支持专项、综合练习和独立汉字错题本。
- tab 超过 10 项时展开/收起，选中隐藏项后仍保持可见，点击主内容区自动收起且不阻断原操作。
- 12 种玩法分为认识拼音、趣味练习、巩固提高三组，默认全部展示，可手动收起并记住偏好。声母、韵母、整体认读统一归入学习范围。
- 63 个基础项目；128 个常见单字、70 个双字词；合法拼读示例、拼写规则及声调听辨题。
- 真人音频点读、保持音高的慢速播放、可选连续听读、播放中状态和失败提示。
- 学习断点、自评认识、收藏、错题、首次作答统计和练习历史；重置记录需要二次确认。
- 成长花园与右上角“我的”均提供错题本、收藏、学习记录、奖励收藏册入口；支持设置本机昵称。
- 星星来源明细、8 张原创 SVG 贴纸、4 枚成长徽章、4 件花园摆件；支持展示、佩戴、庆祝动效及减少动态效果。
- 原创 SVG 小兔插画、柔和配色、儿童学习卡片及响应式布局。

顶部 tab 表示学科下的小功能；拼音的 12 种玩法直接在页面中按组展示。错题本与收藏属于个人复习工具，放在成长花园及“我的”中。学习地图始终对应当前玩法的范围下拉选项，排除“全部拼音”；选中范围后只改变高亮。正式页面不添加无内容的 tab 来凑数量，超过 10 项的行为使用测试数据验证。

奖励规则、解锁条件与旧版记录迁移见 [docs/奖励与个人中心设计.md](docs/奖励与个人中心设计.md)。所有奖励只保存在当前浏览器，不排名、不扣星、不设连续打卡惩罚；星星为累计记录，不消费。

## 音频说明

音频已经随项目放在 `public/audio/` 中，正常运行不需要重新下载。

来源是 [hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn)，署名及许可说明位于 [public/audio/ATTRIBUTION.md](public/audio/ATTRIBUTION.md)，原始说明保存在 [public/audio/UPSTREAM-README.md](public/audio/UPSTREAM-README.md)。文件覆盖清单位于 `public/audio/manifest.json`。

```sh
npm run audio:download
```

以上命令只补充缺失文件，需要访问 GitHub 的 raw 文件域名。已有本地文件会保留，下载失败记录在清单中。

教育内容有以下实际限制：

- 独立 `ong` 录音尚缺，当前明确使用 `dōng` 例音，提示孩子听后半段；不进入需要独立韵母读音的听辨题。
- 部分韵母借助同音或对应完整音节示范；声母借助教学呼读音对应的音节示范，不把它们当作短促本音。部分三拼的分解音尚未覆盖时，会提示自行拼读，答后可听完整音节。
- 13 个双字词缺少上游完整词语录音，使用已下载的音节逐字拼读；界面会作提示。轻声词均使用已有完整词语录音。
- 已核查下载来源、覆盖关系及浏览器播放；仍需普通话教师逐项试听审核，尤其是呼读音、韵母示范和语流变调。自动解码测试不能确认教学发音正确性。

## 验证

```sh
npm test
npm run test:browser
```

浏览器测试通过 Playwright 启动已安装的 Chrome，配置位于 `playwright.config.js`。若机器未安装 Chrome，可以安装 Playwright Chromium 并将配置中的 `channel: 'chrome'` 删除。

多工作区并行开发时，可设置 `PLAYWRIGHT_PORT` 指定独立测试端口；设置后不会复用已有服务。PowerShell 示例：`$env:PLAYWRIGHT_PORT='5186'; npm run test:browser`。若 Node 环境代理导致本地请求失败，可在测试终端设置 `$env:NODE_USE_ENV_PROXY='0'`，不必修改系统代理。

启动开发服务器后，还可验证所有录音能被浏览器解码且不是近乎静音的文件：

```sh
npm run test:audio
```

浏览器测试会在 `artifacts/` 生成电脑、平板、手机预览图。音频检查在同目录生成 JSON 报告。这些产物不加入版本控制。

## 代码结构

| 路径 | 用途 |
| --- | --- |
| `src/data.js` | 拼音、原创字词、规则、练习方式与学科配置 |
| `src/engine.js` | 洗牌、题目生成、唯一答案、首次作答统计和存储读取 |
| `src/app.js` | 页面、对话框、交互、学习记录 |
| `src/hanzi-data.js` | 汉字笔画、笔顺路径、偏旁部首、结构例字与练习题 |
| `src/hanzi-engine.js` | 汉字状态恢复、组题、首次答题记录与错题复习 |
| `src/hanzi.js` / `src/hanzi.css` | 汉字主题页面、逐笔交互和响应式样式 |
| `src/audio.js` | 本地录音播放、停止、慢速和音效 |
| `src/icons.js` | 图标及原创小兔插画 |
| `src/style.css` | 桌面、平板、手机样式 |
| `src/rewards.js` | 奖励规则、去重、旧记录补发、解锁及展示选择 |
| `src/reward-art.js` | 原创 SVG 奖励贴纸、徽章和花园摆件 |
| `src/personal.css` | 三组玩法、个人中心、奖励与庆祝动效样式 |
| `public/audio/` | 录音、覆盖清单、署名与上游说明 |
| `tests/` | 核心逻辑与浏览器行为测试 |
| `docs/需求确认稿.md` | 用户确认的原始需求 |
| `docs/实现与验收.md` | 当前交付范围、验证记录与后续事项 |

新增学科小功能时，在 `subjects` 的 `features` 中配置元数据，并添加对应内容渲染和状态；当前语文包含 `pinyin` 与 `hanzi-structure` 页面。

汉字小节不设解锁条件，可与拼音、古诗积累、朗读和简单表达穿插学习。笔顺采用项目内绘制的 SVG 线条示意，支持下一笔、上一笔、任意笔跳转和从头看，不提供手写识别或书法评分。汉字进度保存在 `bunny-garden-v1` 的 `hanzi` 字段中，与拼音错题和自评记录隔离，共享星星奖励、完成历史和清空确认。具体范围见 [docs/汉字笔画与结构实现与验收.md](docs/汉字笔画与结构实现与验收.md)。
