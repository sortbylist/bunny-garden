## 项目边界

- 学习应用以静态站点发布。交互和记录处理在浏览器完成，免登录，无后端、云同步、追踪或在线教学语音服务。课程文字、图片和音频随站点提供。
- 背诵支持示范朗读、原文与拼音、遮文和自主练习。录音权限始终是可选的，学习、练习、进度和奖励不依赖麦克风。自动语音转写、发音测评和背会认证不在项目范围内。
