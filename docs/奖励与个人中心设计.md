# 奖励与个人中心

面向小学三年级儿童，奖励用于反馈学习行为、鼓励尝试和展示个人成长。奖励不代表考试分数或能力排名。

本文说明个人中心、收藏和进度入口。达标条件及扩课约定见 [奖励规则与扩展约定](奖励规则与扩展约定.md)。

## 入口与信息结构

- 拼音主题采用「学习／练习」分区，按 [内容层级规范](UI与样式规范.md#内容层级) 展示分类。声母、韵母、整体认读等学习分类从对应学习卡进入本节练习。
- 成长花园显示当前课程进度和已展示奖励。小节奖励通过普通练习获得，条件在奖励详情中查看。点击右上角头像打开「我的」，可进入错题本、我的收藏、学习记录和奖励收藏册。
- 错题本按学科和主题筛选，可单题复习或按主题练习。收藏按学科和卡片类型筛选，统一打开原学习卡或练习题。学习记录按日期归集可用的练习成绩，并单列累计浏览与自评进度。
- 收藏、错题与课程共用原卡片和题库。复习使用单独的作答状态，保留课程练习断点。收藏回看及重做用来温习，错题本的独立改正计入学习记录与奖励。
- 右上角星星可点击，直接打开获取规则与奖励流水，说明每颗星星来自哪里。

## 星星规则

| 行为 | 星星 | 去重规则 |
| --- | --- | --- |
| 第一次标记认识学习项目 | +1 | 每个项目只计一次；切换玩法、取消认识后再标记均不重复计数 |
| 第一次答对题目 | +1 | 每个题目只计一次；重试答对也计入，不要求首次作答正确 |
| 在错题本首次独立改正错题 | +2 | 同一错题一生效一次；必须本轮首次作答正确，查看答案后重试不算独立改正 |
| 当天完成有效练习 | +3 | 按设备本地日期，每天一次，不限玩法 |

有效练习指完成一轮题目，其中至少 5 题实际提交过答案；跳过不计作实际作答。拼音配对完成至少 4 对也算有效练习。只浏览、收藏、打开完成弹窗或反复查看奖励不发星星。答错不扣星星。

同一次作答可以同时符合“首次答对”和“独立改正”，此时 +3，并分别记录来源。跨玩法同一题目 ID 不重复发首次答对星星；不同技能题型的题目可分别记录。

星星按学习和练习事件累计，补发奖励依据可核实的学习确认与答题证据。

## 奖励收藏

- 收藏册按贴纸、徽章、奖牌和花园摆件分类。已获得的物品可以展示、佩戴或摆放，更换不消耗星星。
- 未解锁奖励显示明确条件及进度，不设置盲盒、稀有概率或限时失效。
- 学习天数累计计算，不要求连续，不因中断取消奖励。

## 动效与展示

发奖使用短暂的星光和贴纸弹出效果，不遮住答案、不强制中断下一题；奖励解锁时给出名称和原因。完成弹窗打开时，奖励提示显示在该弹窗内。

收藏册中的所有物品均正常彩色展示，已获得物品在右上角显示裁切的圆形“已获得”邮戳，文字右倾，不添加波浪线。无论是否已获得，均可点击放大、拖动或用按钮旋转，并播放与物品内容对应的预览动效；预览不发星星、不解锁奖励。纸飞机沿向右前方倾斜的椭圆轨迹飞一圈，飞远时逐渐缩小、飞回时逐渐放大至原大小并回到原点；探索小地图的小箭头沿原有虚线前进；放大镜只将镜内图案从小变大，主题徽章中心复用对应学习主题的图标。预览右上角关闭即返回原位置，不再放单独的“返回收藏册”按钮。已获得物品另可查看获得时间、佩戴或摆放，以及重播正式庆祝效果。支持系统“减少动态效果”，也可在学习设置中关闭奖励动效。

## 昵称和数据

允许设置 1–12 个字符的昵称，保存到当前浏览器，显示于头像入口、个人中心及成长花园。昵称按文本渲染，不作为 HTML 执行。

所有奖励、装扮、昵称与学习记录共用同一本机存档。清空记录会一并清空奖励和昵称，操作前需要确认。
