# 实现与验收记录

日期：2026-11-07。依据用户确认的《需求确认稿》默认方案实现。

## 页面与范围

实际页面采用浅奶油色纸面、淡粉色拼音卡片、紫色操作按钮和浅绿色成长花园，参考 Bunny Math 的儿童友好圆角、柔和色彩及按钮阴影。小兔与图标为本项目 SVG 绘制，无额外插画依赖。

- 桌面采用左侧学科栏、中间学习区、右侧成长及分类地图。
- 平板将成长与地图放到学习区下方；手机使用抽屉式学科导航。
- 语文的拼音学习展示 12 种玩法，分为三组；声母、韵母、整体认读归入学习范围，错题和收藏放入个人工具。数学、英语当前保留待建设页。
- 学习数据为本机单档案，不包含登录、云同步、麦克风评分或离线安装包。

## 内容实现

| 项目 | 现状 |
| --- | --- |
| 基础拼音 | 63 项，顺序以 a、o、e、i、u、ü 开始 |
| 题库 | 128 个常见单字、70 个双字词，使用原创选项与解释 |
| 认读 | 顺序、分类、随机、跳转、断点继续、自评认识 |
| 练习 | 听辨、音频选项、字词选择、拼读、易混专项、拼写、配对、综合题 |

小学常见分类、拼写规则依据《汉语拼音方案》的通行知识组织，未声称已逐条匹配某一教材版本。正式教学内容还需人工复核，尤其是多音字语境、轻声及变调。

## 音频差异与待完善内容

音频来源、作者、许可声明及上游原文保存在 `public/audio/` 中。基础点读全部有本地音频映射，但“有音频映射”不等于每项都有独立拼音教学录音。

1. `ong` 使用 `dōng` 的例音，卡片提示“注意听后半段”；它被排除在独立拼音听辨题之外。仍需补充合法可分发的独立 `ong` 教学录音。
2. 部分韵母以完整音节示范，例如 `in → yīn`、`ing → yīng`、`ui → wēi`。声母以对应呼读音示范，界面区分呼读音与拼读时的轻短本音。
3. `画画、写字、蓝天、白云、小草、大树、大海、河水、小鸟、小鱼、白兔、山羊、黄牛` 共 13 个词使用逐字音节录音串联，界面明确提示逐字拼读。
4. 三拼中涉及缺失独立 `ong` 的分解示范暂不播放替代音，给出说明；完整音节可正常播放。
5. 连续三声、“一、不”的变调提供解释，未提供完整语流录音课程。
6. 尚未由普通话教师逐条试听，不能以文件可解码或测试通过代替教学质量验收。

## 验证范围

当前结果：15 项核心逻辑测试、19 项 Chrome 浏览器测试及生产构建通过。首次交付的 317/317 个音频已通过解码与非静音检查，本次未改动音频。浏览器测试中的 12 项功能为专用测试数据，不出现在正式页面中。

- 核心逻辑测试覆盖分类数量、标调、洗牌、tab 折叠、选项唯一性、同音干扰排除、首次作答、存储降级及音频映射。
- Chrome 浏览器测试覆盖点读、收藏、刷新恢复、三学科切换、侧栏、12 种玩法及复习工具入口、随机一轮不重复、错题、配对、重置确认、声调听辨及键盘焦点。
- 12 项测试功能验证展开、选中隐藏项后可见、内容区点击自动收起且原按钮操作生效。
- 使用 1440×1100、820×1180、390×844 三种视口检查布局与横向溢出，并生成截图。
- 全量 MP3 浏览器解码及非静音检查单独执行，报告存于 `artifacts/audio-verification.json`。
- 构建使用 `npm run build`，输出为 `dist/`。

目前实际自动化浏览器为 Windows 上的 Chrome。Edge、Safari、实体平板及手机的音频行为尚未实机验证，不将响应式模拟等同于实机兼容性结论。

## 2026-11-08 学习导航调整

- 认读页的“我认识啦”和“还要练一练”保存标记后自动前进，最后一项统一打开本轮完成弹窗。
- 分类完成后提供“下一节”入口，按当前玩法支持的分类顺序推进，并保留顺序/随机等当前玩法。韵母学习自动跳过声母分类；已经完成全部范围或最后分类时明确提示结束，保留重新练习入口。
- 右侧地图仅展示当前玩法“学习范围 / 字词范围”的下拉选项，排除“全部拼音”，保留“字词一起练”。列表只随玩法切换，选中范围后仅更新高亮，不再变成拼音明细、题目或配对内容；没有这两类范围选择的玩法不显示地图。
- 点击地图与选择下拉选项效果一致，保持当前玩法。具体拼音仍可通过学习卡片下方的拼音格子跳转。
