范围：第一阶段 · 数与运算。

## 1. 实现范围

| 主题 | 分类数 | 学习卡 | 练习题 |

每个分类均可直接进入，有概念算例、举一反三和可展开的参考思路。开放思考由学习者自评。完整分类见 [数学学习分类规划](数学学习分类规划.md)。

## 2. 页面与交互

- 数学入口直接打开第一阶段主题，顶部切换五个主题，页面标题上方显示阶段，页面内选择分类。
- 复用语文已有的纸张学习卡、例题区域、分类按钮、学习卡目录、练习选项、反馈、结果页和成长花园。
- 教学图解包括数位表、分组圆点、加减乘竖式和两位数乘法拆分；采用本地 HTML/CSS，无外部图片依赖。
- 学习卡支持自评认识、前后切换与直接选择。每轮可选 10/20/30 题，分类只有 12 题时按实际题量出题。
- 综合练习覆盖主题各分类，新一轮优先抽取未练题。开始新轮前提示会替换未完成的一轮，也可继续上次练习。
- 答错允许重试，先看答案算跳过，首次成绩不被覆盖；错题只有在新的错题复习轮中首次独立答对才移出。
- 成长花园展示当前主题进度，错题本和学习记录从「我的」进入，可按学科和主题查看。

## 3. 数据存储

- 主题在 `src/math-topics.js` 注册，各主题内容拆分到 `src/math-*-data.js`。
- 复用 `src/chinese.js`、`src/chinese-engine.js` 和 `src/chinese-practice.js`；通过主题的 `subject` 区分数学的算例、思路文案与辅助工具。
- 数学进度按主题和分类存入 `subjects.math.stages.math-1`。主题、学习卡和题目使用 `math-` 前缀。
- 刷新时按保存的题目标识从课程题库恢复。增量扩课时允许同版本存档缺少新增课程节点。格式与校验规则见 [本机数据与备份规范](../本机数据与备份规范.md)。
- 数学、语文和英语的进度按字段纳入应用根数据，统一保存、备份和清空。
- 阶段名称按学科解析，避免数学“第一阶段”被误显示成语文“字词基础”。

## 4. 验收

自动检查包含：

- 内容覆盖、标识唯一、选项唯一、题目答案及关键计算边界。
- 五主题专项和综合组题、未练题优先、首次成绩、跳过、错题复习和损坏存档恢复。
- 浏览器中的主题与分类切换、参考思路、自评、奖励去重、错题、学习记录、跨学科隔离、刷新和清空。
- 与语文已有页面的卡片、选项、布局和成长花园样式一致性。
- 1440px、820px、320px 页面及练习无横向溢出。

验证命令：

```sh
npm test
npm run build
npm run test:browser
```

独立 worktree 测试时按 README 设置 `PLAYWRIGHT_PORT`，避免复用其他工作区服务。截图存入忽略的 `artifacts/`。
