## 2. 页面与交互

- 数学入口直接打开第一阶段主题，顶部切换五个主题，页面标题上方显示阶段，页面内选择小分类。
- 复用语文已有的纸张学习卡、例题区域、小分类按钮、学习卡目录、练习选项、反馈、结果页和成长花园。
- 教学图解包括数位表、分组圆点、加减乘竖式和两位数乘法拆分；采用本地 HTML/CSS，无外部图片依赖。
- 学习卡支持自评认识、前后切换与直接选择；每轮可选 10/20/30 题，小分类只有 12 题时按实际题量出题。
- 综合练习覆盖主题各小分类，新一轮优先抽取未练题；开始新轮前提示会替换未完成的一轮，也可继续上次练习。
- 答错允许重试，先看答案算跳过，首次成绩不被覆盖；错题只有在新的错题复习轮中首次独立答对才移出。
- 成长花园与“我的”均提供当前主题错题和记录入口，沿用已有星星去重、完成历史与清空确认。

## 3. 数据与兼容

- 主题在 `src/math-topics.js` 注册，各主题内容拆分到 `src/math-*-data.js`。
- 复用 `src/chinese.js`、`src/chinese-engine.js` 和 `src/chinese-practice.js`；通过主题的 `subject` 区分数学的算例、思路文案与辅助工具。
- 数学进度存入 `bunny-garden-v1` 的 `topics` 字段，主题、学习卡和题目使用 `math-` 前缀，和语文错题、自评、答题断点隔离。
- 刷新时根据课程原始数据恢复，过滤外来标识并纠正被改写的题目。旧存档自动补齐数学默认状态。
- 不改变英语的独立存储；清空全部本机记录时同时清除数学、语文和英语进度。
- 阶段名称按学科解析，避免数学“第一阶段”被误显示成语文“字词基础”。

## 4. 验收

自动检查包含：

- 内容覆盖、标识唯一、选项唯一、题目答案及关键计算边界。
- 五主题专项和综合组题、未练题优先、首次成绩、跳过、错题复习和损坏存档恢复。
- 浏览器中的主题与小分类切换、参考思路、自评、奖励去重、错题、学习记录、跨学科隔离、刷新和清空。
- 与语文已有页面的卡片、选项、布局和成长花园样式一致性。
- 1440px、820px、320px 页面及练习无横向溢出。

验证命令：

```sh
npm test
npm run build
npm run test:browser
```

独立 worktree 测试时按 README 设置 `PLAYWRIGHT_PORT`，避免复用其他工作区服务。截图存入忽略的 `artifacts/`。
