# 本机数据与备份规范

## 数据结构

语文、数学、英语统一按 **学科 → 阶段 → 主题 → 分类** 存放。首发统一格式为 `version: 1`，浏览器 `localStorage` 使用 `bunny-garden-v1`。键名由数据版本推导，备份的 `data` 与本机数据采用同一结构。

| 位置 | 数据归属 |
| --- | --- |
| `profile` | 昵称、成长星流水、奖励解锁、待展示奖励和当前装扮 |
| `settings`、`navigation` | 全局学习偏好、当前学科、侧栏状态和拼音玩法选择 |
| `subjects[学科]` | 上次选择的 `selectedStage` 和已上线的 `stages` |
| `stages[阶段]` | 上次选择的 `selectedTopic` 和该阶段的 `topics` |
| `topics[主题]` | 主题设置、当前分类和学习卡、综合练习与综合练习记录 |
| `categories[分类]` | 浏览、自评、收藏、错题、抽题记录、专项练习及断点、草稿、排序、笔顺和奖励达标证据 |

三科的阶段入口、本机存档和 JSON 备份使用同一套课程归属。数学的数与运算位于 `subjects.math.stages.math-1`。语文第一阶段的首个主题为拼音学习，单韵母记录保存在 `subjects.chinese.stages.chinese-1.topics.pinyin.categories.single`。英语第一阶段的首个主题为自然拼读，课次记录保存在 `subjects.english.stages.english-1.topics.phonics.categories`，跨课练习和公共设置保存在自然拼读主题下。自然拼读的模块用于课程地图分组。

阶段、主题和分类键使用稳定的课程标识。语文、数学和英语主题练习保存题目标识、选项顺序与作答状态，恢复时从课程题库取回题干和解说。拼音即时生成的练习保留题目快照。

同一练习范围的不同题量分别保存。主题练习的当前轮保留在 `round`，其他轮次按范围与题量记录在同一主题或分类的 `rounds`。只有 `round` 的既有记录也可恢复。

## 导入与导出

- 从「学习设置 → 数据备份」导出完整 JSON。外层包含 `format`（`bunny-learning-garden`）、`version`（首发为 `1`，与 `data.version` 一致）、`producerVersion`、`exportedAt` 和 `data`。`producerVersion` 记录导出时的应用版本，数据版本用于格式校验和未来迁移。
- `exportedAt` 和导出文件名均取自点击导出时的系统本地时间，并包含当时的时区偏移。例如，`2026-11-21T14:30:05.123+08:00` 对应文件名 `小兔学习乐园-完整备份-2026-11-21T14-30-05-123+08-00.json`。
- 导入限制为 20 MB。先校验版本、字段类型和课程归属，再展示昵称并请求确认。用户确认后单次写入，成功后刷新。取消、校验失败或写入失败均保留当前数据。
- 同版本归档缺少新增的课程节点或全局设置时，读取后为缺失项补默认值，保留原有数据。已存在的记录仍校验结构、内容标识和归属。无法读取本机档时进入临时学习模式，暂停自动保存，直到成功导入或主动清空。
- 发布前的双键结构和试开发备份不属于首发格式，当前无跨版本迁移。高于当前版本的备份会在写入前被拒绝。
- 备份会包含昵称、草稿和学习记录，请妥善保管文件。

## 版本升级约定

- 增量扩课、展示调整和可默认的设置沿用数据版本。课程、题目和奖励 ID 保持稳定。
- **破坏性数据变更必须将 `version` 加一，同时提供前一版本到新版本的迁移。** 本机读取和备份导入共用逐级迁移，依次执行 `1 → 2 → 3` 等相邻步骤。每步按固定的对应版本契约校验和转换。迁移只转换数据，奖励和学习行为由正常应用流程处理。
- 实现跨版升级时，先在内存中完成迁移和校验，再写入目标版本键。写入并验证成功后，用独立迁移记录标记旧档已处理，保留原档。重启优先使用有效的新档，避免升级重跑覆盖后续进度。导入文件先预览并确认，原始文件保持原样。
- 每次发布新数据版本时，保留各已发布版本的样本。验证相邻迁移、最早版本直接打开当前应用、旧备份导入与重导出、失败时保留数据，以及按用户确认清空留存档和迁移记录。

## 实现与验证

`src/learning-data.js` 负责课程路径、编码和校验，`src/storage.js` 负责本机读写，`src/backup.js` 负责备份外层信息与导入。扩课时，在对应学科的课程定义中登记阶段、主题与分类，并在现有测试中验证分类归属、刷新恢复、备份一致性与失败时的数据保留。
