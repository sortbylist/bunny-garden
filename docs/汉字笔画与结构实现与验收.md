# 汉字笔画与结构：实现与验收

日期：2026-11-10。依据《语文学习分类规划》第一阶段第 1 项实现。

## 入口与学习原则

- 语文学科新增“汉字笔画与结构”功能，与“拼音学习”并列，不替代拼音中的“看字选拼音”玩法。
- 六个分类均可直接进入。
- 页面提示允许穿插古诗积累、朗读、口头表达和简单写作；本次不实现其他规划主题。

共 109 个学习项目和 358 道题，扩充前为 93 项、204 题。这是基础示例课程，不声称涵盖所有笔画、偏旁、结构或某一教材的全部生字。例字自动换行以适应窄屏；学习页只显示拼音辅助开关，进入练习后才显示新一轮题数设置。

笔顺路径为项目内绘制的 SVG 线条，使用浅色完整字作参照、深色已写笔画、紫色当前笔画和绿色起笔点。支持“下一笔”“上一笔”“从头看”及逐笔跳转；当前笔画有短暂书写动效，可通过学习设置或系统减少动态效果关闭。界面明确标注为线条示意，不是楷书字帖、手写识别或书写评分。

## 练习、记录与奖励

- 专项练习从当前分类抽题，可选最多 10、20、30 题，题量不足时按实际数量出题。综合练习覆盖全部六个分类，同轮题目各不相同、选项随机。新轮优先抽取未出现的题目，抽遍范围后重新循环。
- 题型包含笔画辨认、第一笔及后续各笔、笔画数、偏旁名称、每个例字的部首及三类结构判断。
- 新增可关闭的难词拼音，例如横撇、竖心旁、宝盖头、安宁。保留笔顺主图、步骤和部件展示的清晰字形。设置按主题保存，切换题数立即打开对应题量的练习，切回原题量即可恢复原题目和作答进度。
- 答错后可重试或看答案；首次结果单独记录，重试答对不修改首次正确率。查看答案后显示解释，不算答对。
- 汉字错题与拼音错题分开保存；仅在汉字错题复习的新一轮中首次独立答对才移出错题。学习页、个人菜单、成长空间和学习记录提供汉字错题入口。
- 自评认识、首次答对、独立改错、每日有效练习复用现有星星奖励规则，使用 `hanzi:` 标识去重，不重复发奖。
- 完成一轮后写入现有学习历史，重复点击或刷新不重复记录。
- 状态保存在 `subjects.chinese.stages.chinese-1.topics.hanzi-structure`。主题记录所选分类与学习项目，各分类保存笔顺步骤、自评、错题和专项练习，综合练习保存于主题。切换学科、功能或刷新后均可继续。
- 旧数据自动获得初始汉字状态；损坏的汉字题目或记录局部过滤。浏览器存储被禁用时仍能临时练习。现有“清空本机学习记录”二次确认同时清空汉字数据。
