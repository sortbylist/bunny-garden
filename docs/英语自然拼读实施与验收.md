# 英语自然拼读：确认方案、实现与验收

日期：2026-11-09  
状态：用户已确认开发；已接入内容预览与文字训练。**英音教学音频尚未就绪，不能视为完整的可听自然拼读课程。**

本文件取代《英语自然拼读需求确认稿.md》中最初的美音要求。旧稿保留作历史记录，其中其他英语分类、隐私和学习原则的建议继续适用，但遇到冲突以本文件和用户最新要求为准。

## 1. 用户已确认的决定

- 只使用英式英语，不使用美式录音或不确定口音的替代语音。
- 本次只开发自然拼读；主题词汇、听力、情景口语、分级阅读、句型语法、拼写书写、看图表达等其他分类仅记录规划，不增加空功能入口。
- 孩子正在学习 Cambridge Power Up 1。自然拼读保持独立、系统的顺序，不专门做教材同步。
- 在合适的规律下优先采用熟悉的生活、家庭、校园词汇和情境；也保留未背过的新词，检验迁移。
- 不复制 Cambridge 教材插图、音频、故事、练习包，不暗示官方合作或课程认证。
- 沿用中文界面、本机存储、无登录、无麦克风、无自动发音评分和无付费默认授权的边界。

## 2. 当前英音标准

以清晰的标准英国英语教学口径、非卷舌示范为主。英国英语内部也有差异，不把该口径描述成所有英国人唯一的发音。

| 内容 | 当前约定 |
| --- | --- |
| 语言标记 | en-GB；实际口音另行试听审核，不只看标签 |
| 拼写 | colour、favourite 等英式习惯 |
| 字母 Z | 字母名 zed；和字母音分开 |
| 短元音 | /æ e ɪ ɒ ʌ/；词典中的 /e/ 与 /ɛ/ 记法差异另作说明 |
| goat 元音 | /əʊ/ |
| car / bird / teacher | 单独读时分别采用 /kɑː/、/bɜːd/、/ˈtiːtʃə/ 一类非卷舌示范 |
| 元音前 r | red、frog 等仍读出；不能把非卷舌理解为所有 r 都不读 |
| air / near | 教学参考 /eə/、/ɪə/；现代英国英语存在合理变体，录音需统一核查 |
| bath / hot / saw | 本课程目标分别为 /bɑːθ/、/hɒt/、/sɔː/，不直接套用美音规则 |
| u_e / ew | cube 的 /j/ 与 /uː/ 要分清；blue、rule 与 new、few 结合具体词学习 |

音标默认放在家长提示，不作为儿童先修课。字形拆看不等于音素分解；字母名不能代替字母音；不使用中文谐音注音。

## 3. 课程与内容

已编写 12 个模块、48 个短课，结构为：

1. 听音准备与字母认知：3 课。
2. 短元音与基础合音：6 课。
3. 辅音连缀与词尾：6 课。
4. 辅音组合与常见拼写：4 课。
5. 长元音与词尾 e：4 课。
6. 常见元音组合：5 课。
7. 带 r 的元音：5 课。
8. 其他元音与双元音：4 课。
9. 多读音、静音字母与特殊高频词：4 课。
10. 多音节与重弱读：3 课。
11. 词尾变化与词素：2 课。
12. 熟悉场景与综合阅读迁移：2 课。

### 数量与口径

| 资源 | 当前实际数量 | 限制 |
| --- | ---: | --- |

| 词条 | 914 个不同拼写词形 | 包含屈折形式，不是 914 个不同词根；不是全部要求三年级掌握 |
| 字母参考 | 26 个 | 大小写与英式名称参考；尚无已审核字母名/音素录音 |
| 词义题 / 字母拼词题 | 各 914 道 | 原创释义与字母块；不是听写或独立发音测验 |
| 规律题 | 48 道 | 每课 1 道；当前并非每课都已有 20 道多样化规律训练 |
| 大小写题 | 26 道 | 不依赖音频 |
| 原创共读文本 / 理解题 | 36 篇 / 36 道 | 每篇目前 1 道理解题，未达到初始建议的每篇 2～3 道 |

题目按不同目标词/目标知识点计数，不以打乱选项计数。数字上的文字题总量不能替代音素听辨、合音、分音等训练类型的覆盖。

### 文本定位

36 篇故事均为原创，附前置规则和需预教词提示，但未逐词完成先修覆盖审核，因此明确标为“家长共读”，**不宣称均为当前课孩子可以独立解码的读物**。普通理解题结果与独立测验分别处理。

正式可拼读阅读仍需：逐词标注已学规则、少量预教特殊词、审核自然程度与适龄性、补充理解题，并配完整英式语流音频。

## 4. 已接入的操作

- 英语 → 自然拼读入口，48 课选择与 12 站课程地图。
- 顺序词卡、范围内随机词卡、词义选择、字母块拼词/直接输入、规律题。
- 大小写配对题、可跳过的文字起点参考；不冒充听觉或口语诊断。
- 家长共读故事、故事选择、理解选择及查看答案。
- 收藏、自评会读、还要练、浏览记录；自评后自动前进。
- 客观题首次结果、重试、跳过、错题、新一轮独立改正与复习安排。
- 每轮 5/10/20 题；题池不足按真实题数出题，不重复凑数。
- 当前轮未完成内容保留；重新开始需要确认，保留错题与历史。
- 拼词输入、字母选择、课次与词卡位置可刷新恢复。
- 英语记录独立存储在 `bunny-phonics-gb-v1`，不覆盖语文 `bunny-garden-v1`。
- 全局“清空本机记录”同时重置语文、英语和原有个人中心数据，需要原有二次确认。
- 正式音频门控、失败提示、慢速播放、切换页面停止播放；目前不使用系统 TTS。

英语的客观题和自评尚未纳入原有语文奖励规则，不能把原有成长星自动解释为英语学习成绩。现有个人中心和语文奖励保持原有行为。

## 5. 音频与授权

发布清单位于 `public/audio/phonics/manifest.json`，当前为空。只有具备本地合法路径、en-GB、授权来源、真实审核者/日期且状态为 `approved` 的项目才可播放及支持正式听辨。

已查询的 Wiktionary `cat` 词条同时有英美口音，英式文件实际为 “a cat”，不能截取或冒充独立 cat 录音。尚未找到并审核可覆盖整套课程的合法音源。

已增加候选收集脚本：

```sh
npm run phonics:audio:collect
node scripts/collect-phonics-audio.mjs --limit=48
node scripts/collect-phonics-audio.mjs --limit=48 --metadata-only
node scripts/collect-phonics-audio.mjs --limit=48 --metadata-only --powershell
```

脚本仅查询明确 UK 命名的公开候选、检查许可元数据、保留作者与来源，写入 `public/audio/phonics/candidates/` 的待审核队列，**不自动更新发布清单，不设置虚构人工审核状态**。`--metadata-only` 不下载音频，`--powershell` 显式使用 Windows 系统网络接口。默认 Node 请求采用 IPv4 优先；遇到下载端 429 时停止后续下载，源 API 失败时保存已取得的记录，不把网络错误页面原文写进公开清单。

2026-11-09 实际网络结果：在用户表示已配置系统代理后重试，Node 直连曾成功取得首批元数据，但出现音频下载 HTTP 429 和后续请求超时。Windows 系统接口成功完成 48 个示例词的命名候选核查：13 条来源/许可记录、35 个无匹配候选，下载文件 0 个、发布音频 0 个。完整待审核元数据位于 `public/audio/phonics/candidates/review-queue.json`。

13 个候选为 sun、bed、hot、hand、cake、rain、blue、hair、door、book、city、head、family；来源署名均为 Association Shtooka, Judith Franck，元数据声明 CC BY 3.0 US。**US 在此是许可证司法辖区标记，不代表录音是美音；实际口音仍未试听确认。**这些文件不是已下载录音，更不是已审核课程音源。不能以来源数量代替覆盖完成。

获得音源后，仍须逐条检查：实际口音、完整词形、是否附带冠词、独立音准确性、词尾附加元音、静音/截断/噪声、重音、自然语流及再分发授权。文件可解码与自动测试通过都不能替代教学试听。
