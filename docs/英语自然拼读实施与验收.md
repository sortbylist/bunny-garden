# 自然拼读：学习内容与使用说明

## 可以学什么

课程包含 12 个模块、48 课，从字母和声音开始，逐步学习小词、字母组合、长词和故事。

| 学习阶段 | 内容 |
| --- | --- |
| 准备出发 | 大小写字母、字母名与字母音、词首和词尾的声音 |
| 短元音 | cat、bed、pig、hot、sun 等小词 |
| 辅音连缀 | bl、cr、st 等词首组合和常见词尾 |
| 辅音组合 | sh、ch、th、ng、ck、tch、dge 等 |
| 长元音 | cap/cape、kit/kite 等词语比较 |
| 元音组合 | ai、ay、ee、ea、oa、ow、igh 等 |
| 带 r 的元音 | ar、or、er、ir、ur 等拼写 |
| 更多元音 | book/moon、coin/toy、out/cow 等 |
| 特殊读法 | 多种读音、不发音字母和常见特殊词 |
| 长词探索 | 音节、复合词、重音和弱读 |
| 词尾变化 | -s、-es、-ed、-ing 等 |
| 阅读迁移 | 校园、家庭、动物等情境中的词和故事 |

目前可以学习 914 个不同词形，阅读 36 篇故事。可以按课程顺序学习，也可以选择熟悉的内容，不要求一次学完。

## 怎样开始

1. 打开“英语”，选择“自然拼读”。
2. 在顶部选择“课程学习”，再从“学习小地图”选择一个小节，看看“本课发现”，找一找拼读规律。
3. 先试着读单词，再点“听一听”。需要时可以选择慢速。
4. 会读的词点“我会读了”，还不熟悉的词点“还要练一练”。
5. 做几道词义、拼写或规律练习，再去错题里复习。

每次学一点，累了就停一停。下次回来可以继续。

顶部选择玩法，小地图选择该玩法下的小节。切换小节会保留当前玩法；当前小节显示在内容标题下。随机词卡、词义、拼词、规律和听词练习也可以在地图中选择“全部课程一起练”。

选择“故事共读”后，小地图显示 36 篇故事，可以直接点选。收藏、错题和学习记录不需要选课，不显示课程地图。

“我的成长花园”显示自然拼读的学习进度，并提供“错题本”“我的收藏”“学习记录”入口。错题本只收录自然拼读的错题；没有错题时按钮不可点击。语文各页也有成长花园，分别显示当前页的进度与错题本。

## 可以怎么玩

| 玩法 | 学习方法 |
| --- | --- |
| 课程学习 | 按本课顺序读词，听一听，再跟着读 |
| 随机词卡 | 换个顺序，看看自己是否还记得 |
| 词义选择 | 读单词，选择它的意思 |
| 字母拼词 | 点选字母或直接输入，拼出目标词 |
| 找规律 | 根据例词发现字母和声音的关系 |
| 听词选词 | 完整听一次，再选择听到的词 |
| 故事共读 | 自己读或和家长一起读，听故事，回答小问题 |
| 收藏与错题 | 集中复习喜欢的词和需要再练的题 |

## 给家长的小建议

- 先从孩子熟悉的小词开始，不需要先背完全部字母表。
- 字母的名字和它在词里的声音要分开认识。
- 听过、跟读和自己独立读出是不同的练习，可以轮流进行。
- 遇到长词先分段，再连起来；不熟悉的词可以一起听、一起读。
- 故事适合陪读。先理解人物和事情，再试着用自己的话讲一讲。
- 自评“我会读了”是孩子的学习记录，可以结合实际朗读一起回顾。
- 单词点读和听词题之外，还可以口头练习找词首音、合音和分音。

## 学习记录

学习位置、收藏、错题和练习历史会保留在当前设备。首次作答与重试分别记录，答错后可以继续尝试。英语与语文的进度分别保存；清空本机学习记录会一起清除。
