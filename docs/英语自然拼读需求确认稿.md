# 英语学习：内容规划

本次先开展自然拼读，面向小学三年级学生。课程按自己的拼读路线组织，可以结合孩子正在学习的教材，选择熟悉的生活、家庭和校园情境，不要求逐单元同步。

## 自然拼读的学习目标

- 认识大小写字母，区分字母名和字母音。
- 听出词首、词中和词尾的声音，尝试合音与分音。
- 从短词开始，认识常见辅音、元音和字母组合。
- 比较有共同拼写的小词，逐步读出没有背过的新词。
- 学习常见特殊读法、词尾变化、长词音节及重音。
- 把读词、词义、拼写与故事理解结合起来。

## 课程路线

| 模块 | 课数 | 主要内容 |
| --- | ---: | --- |
| 听音准备与字母认知 | 3 | 大小写、字母名与字母音、词首词尾、合音与分音 |
| 短元音与基础合音 | 6 | a/e/i/o/u、am、at、map、cat、bed、pig 等 |
| 辅音连缀与词尾 | 6 | bl/cl/fl、br/cr/fr、st/sp/sw、常见词尾和三个辅音组合 |
| 辅音组合 | 4 | sh/ch/th/ng/ck、tch/dge、双写、qu/x |
| 长元音与词尾 e | 4 | cap/cape、kit/kite、词尾 e 和开音节 |
| 常见元音组合 | 5 | ai/ay、ee/ea、oa/ow、igh/ie、ue/ui/ew |
| 带 r 的元音 | 5 | ar/or/er/ir/ur、air/are、ear/eer 等 |
| 更多元音 | 4 | oo 两种声音、oi/oy、ou/ow、au/aw/al |
| 多读音与特殊词 | 4 | c/g/y、ea、静音字母、常见高频特殊词 |
| 音节与长词 | 3 | 闭音节、开音节、复合词、辅音-le、重音与弱读 |
| 词尾变化与小词素 | 2 | -s/-es、-ed、-ing、常见前后缀 |
| 综合阅读与复习 | 2 | 熟悉场景、新词迁移、故事理解和个人易错点 |

课程可按需要跳转，不用完成页数或点击次数代表掌握。音标是辅助提示，不是孩子开始学习前必须背诵的内容。

## 练习安排

词卡、词义选择、字母拼词、规律题、听词选词和故事共读互相配合。单词朗读、理解意思、听懂和拼写分开练习。

练习先少后多，按孩子的节奏进行；答错可以重试，不设强制倒计时。收藏、错题和学习记录帮助下一次复习，不做排名和连续打卡惩罚。

故事从熟悉的小词逐步延伸，必要时由家长陪读。理解题帮助寻找人物、地点、先后顺序及简单因果，不把听过故事等同于能独立读出。

## 其他适合三年级的英语分类

以下内容先记录规划，不作为本次同时开发的范围。

| 顺序 | 分类 | 建议内容 |
| --- | --- | --- |
| 优先 | 主题词汇 | 家人、文具、颜色数字、身体、动物、食物、衣服、房间、玩具、天气与日常活动 |
| 优先 | 听力小练习 | 听词选图、听指令、短句和简单对话，辨认位置、数量、人物与喜好 |
| 优先 | 情景口语 | 问候、自我介绍、介绍家人、表达喜好、课堂求助、购物和点餐 |
| 优先 | 分级阅读 | 故事情节、人物地点、简单因果、预测、复述和阅读兴趣 |
| 后续 | 句型与语法小积木 | I am…、I have…、I like…、Can you…?、Where is…?，配合具体情境 |
| 后续 | 拼写与书写 | 字母书写、大小写、词间空格、标点、主题词听写和短句整理 |
| 后续 | 看图表达与小写作 | 补全一句话、描述人物物品、写简单小卡片 |
| 兴趣拓展 | 儿歌与童谣 | 节奏、重音、押韵和动作指令 |
| 兴趣拓展 | 生活与文化 | 日期时间、礼貌、食物、运动和节日常识 |
| 按需 | 课内同步 | 根据孩子实际使用的教材整理词汇、句型和复习 |

建议先做好自然拼读，再逐步增加主题词汇、听力、口语和阅读。日常学习中这些能力可以并行练习，不必等完整学完拼读才读故事。
