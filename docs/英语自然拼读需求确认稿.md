## 1. 本轮结论与范围

### 1.1 已明确的要求

- 在现有“英语”学科下增加“自然拼读”，面向小学三年级学生。
- 所有英语教学示范和训练音频只使用美式英语，不混入英音。
- 内容尽量完整，兼顾零基础补齐、已有基础的查漏补缺和进阶学习。
- 先形成文档，与用户确认是否遗漏；明确确认后，才开始设计与生成。
- 同时提出适合三年级的其他英语小分类，但这些建议不自动视为已批准开发。

### 1.2 当前项目约束

现有项目是中文界面的静态网页应用，无后端、无登录，学习记录保存在当前浏览器。英语目前没有小功能，语文已有拼音学习。本次扩展应保留已有功能和记录，不把汉语拼音的发音与拼读规则直接套用到英语。

建议“自然拼读”作为英语下一个独立小分类；字母、短元音、组合音、拼写等是内部课程或训练，不各自挤占学科顶部 tab。原有顶部超过 10 项的展开/收起规则继续适用，不添加空入口凑数。

### 1.3 本稿的内容来源与完成状态

本稿依据已有语言教学知识整理知识体系，训练示例为本次原创编写，不复制商业课程、题库或绘本。第 12 节提供后续核对用的公开资料入口；本轮没有联网逐页核验，也没有下载、采购或审核音频。

文中的课时、词数和题数均为**建议交付目标，不是已经完成的资源数量**。教学顺序、例词、录音和可拼读文本，在正式发布前仍须逐项审核。

## 2. 教学目标与适龄原则

### 2.1 希望孩子能够做到什么

1. 分清字母名称与字母在单词中的常见声音，例如字母 B 的名称与 /b/ 不同。
2. 听出单词中的音素，将声音合成为单词，也能把单词拆成声音。
3. 运用已学字母—声音关系，尝试读出没背过、但规则已学过的单词。
4. 从听音、分音到选字母和拼写，建立“读”和“写”的双向联系。
5. 识别常见多字母组合、长元音、r 控制元音及多音节词的基本结构。
6. 读懂适合当前水平的短句和可拼读小故事，不停留在孤立词卡。
7. 对不完全符合已学规律的高频词，知道哪些部分可拼、哪些部分需特别记忆。

自然拼读不能替代词义学习、听说输入、阅读理解，也不能保证“所有词见词能读、听音必定能拼对”。英语存在一音多拼、一拼多音、重音和例外，需要明确教学边界。

### 2.2 三年级不等于统一英语水平

- 年龄定位约 8～9 岁，但按实际能力分级，不按年龄强制从头学习。
- 提供约 15～20 题、可跳过的起点检查，覆盖字母音、合音、分音、常见词解码；结果只用于推荐学习起点，不作为能力诊断。
- 听力选择题不能证明孩子能独立朗读；独立读词由孩子跟读自评或家长观察，和客观答题分别记录。
- 每次建议 10～15 分钟，每课可拆成多次完成，不强制计时或一天学完。
- 中文短指令、英语示范；音标供家长或教师展开查看，不要求孩子先学国际音标。
- 先确保孩子理解基本词义，再做有意义的拼读；允许词义预习，但纯解码测验不提前用图片或中文泄露答案。
- 不用汉字、中文谐音或汉语拼音给英语注音。

## 3. “只包含美音”的具体标准

### 3.1 发音基准

采用通用美式英语（General American）作为教学基准，优先同一位或发音风格一致的示范者。使用美式拼写，如 color、favorite、center；字母 Z 读 zee。不制作英美对比题，也不加入英音选项当干扰项。

- 单词通常保留词尾及元音后的 r，如 car、bird、teacher。
- 短元音教学采用 /æ/、/ɛ/、/ɪ/、/ɑ/、/ʌ/ 等常见美式标注；具体音标体系全文保持一致。
- /ʊ/ 与 /u/ 的对照如 book / moon；词典中的 /uː/ 等符号差异不直接当作口音差异。
- /ɹ/ 表示美式 r；/ɝ/、/ɚ/ 用于相关重读、非重读 r 色彩元音。儿童界面以听音和短提示为主。
- 美音内部存在合理差异，例如 cot–caught 合流与否。选定示范口径并记录，不把两者强行设为所有美音使用者都能听辨的最小对立题。
- 不用“英语恰好只有 44 个音”作为无条件定义；音素统计取决于口音与分析体系。
- 初期用清晰、自然的教学速度。后期可提供 water 等词中的美式闪音示范，但不要求孩子把所有 t 读成 d，也不将弱读、连读作为基础通关门槛。

### 3.2 不可妥协的音频要求

1. 每段正式英语音频都标记 en-US，并由人工确认实际读音；标签或服务设置不是合格证据。
2. 字母名、独立音素、分解拼读、完整单词、短句分别录制或审核，不能相互冒充。
3. 尽量示范干净的辅音，不在 /b/、/t/、/k/ 后人为加上“呃”；塞音短促，持续音可适度延长，不强行把所有声音拉长。
4. /ŋ/ 不额外加 /g/；/θ/、/ð/、/v/、/w/、/ɹ/ 等提供准确示范及简短口型说明。
5. 不把逐字母名称朗读当作拼读，不用普通 TTS 直接读单个字母来充当音素录音。
6. 单词与句子必须有完整自然读音；分解音拼接只用于明确标记的分音演示，不能冒充自然词音或自然语流。
7. 正常播放、重复播放、保持音高的慢速播放；默认不自动连续播放。切换内容停止上一段，避免叠音。
8. 音频缺失或不合格时明确标记，相关依赖音频的题目不进入正式训练；不静默改用英音或浏览器不确定口音。
9. 不把浏览器系统语音作为默认教学音源；即便存在 en-US voice，也必须单独验证才可作非核心补充。

## 4. 完整课程地图

建议规划 **12 个模块、48 个短课单元**。其中第 1～9 模块为基础主线，第 10～12 模块为逐步开放的进阶内容；全部列入自然拼读内容目标，不要求三年级学生立即掌握所有进阶项。

课时是内容组织单位，不等同于学校一节课。初学阶段不必先背完 26 个字母才开始合音，可用已学的少量字母尽早练习。

| 模块 | 建议单元数 | 覆盖知识与代表例词 | 教学边界 |
| --- | ---: | --- | --- |
| 1. 听音准备与字母认知 | 3 | 韵脚、词首音、口头合音/分音；26 个字母大小写、字母名与常见字母音 | 听觉活动可不显示文字；字母认知后续螺旋复习，不在三课内要求完全熟练 |
| 2. 短元音与基础合音 | 6 | a/e/i/o/u：cat、bed、pig、hot、sun；VC/CVC：am、at、map、sit、cup | 先教够用的辅音；CVC 指音素结构，不能机械地只数字母 |
| 3. 辅音、辅音连缀与词尾 | 6 | b/d/p/q 视觉辨认；bl/cl/fl/gl/pl/sl，br/cr/dr/fr/gr/pr/tr，sc/sk/sm/sn/sp/st/sw；词尾 -nd/-nt/-mp/-st/-sk；后续 spr/str/scr/spl | 连缀中各辅音仍保留；q 常与 u 一起教，不虚构固定的独立 q 音 |
| 4. 辅音组合与常见拼写 | 4 | sh、ch、th 两音、wh、ng、ck；tch/dge；ff/ll/ss/zz；qu、x | sh 等组合与辅音连缀分开；x 常对应 /ks/ 两个音，qu 常对应 /kw/；wh 基础按所选美音 /w/ |
| 5. 长元音与词尾 e | 4 | a_e、i_e、o_e、u_e、少量 e_e；cap/cape、kit/kite、hop/hope、cub/cube；开音节 me、go | silent e 是常见模式而非绝对规则；have、give 单独标注；u 可为 /ju/ 或 /u/，按具体词教 |
| 6. 常见元音组合 | 5 | ai/ay、ee/ea、oa/ow、igh/ie、ue/ui/ew；rain、day、feet、sea、boat、snow、night、pie、blue、fruit、new | 不使用“两元音相遇，前者读字母名”作为通用定律；先主读音再讲少量例外 |
| 7. r 控制元音 | 5 | ar、or、er、ir、ur；car、fork、her、bird、turn；后续 air/are、ear/eer、ore | er/ir/ur 在常见重读词中可以同音，不能只听音要求唯一选出拼写；ear 等多读音按词分组 |
| 8. 其他元音与双元音 | 4 | oo 两音、oi/oy、ou/ow、au/aw、部分 al；book/moon、coin/toy、out/cow、sauce/saw、ball | ou/ow/oo 并非各有唯一读音；/ɔ/ 与 /ɑ/ 的呈现遵循选定的美音口径 |
| 9. 多音字母与高频特殊词 | 4 | soft c/g：city、gem；y：yes、my、happy；ea：sea/head；ow：snow/cow；常见不规则部分与静音字母 kn/wr/mb | c/g 规律讲“常见”不讲“必定”，get/give 等说明例外；read 等异读词必须有语境 |
| 10. 音节与双音节解码 | 3 | 闭音节、开音节、元音-e、元音组合、r 控制、辅音-le；rabbit、robot、sunset、picnic、table；重音、非重读弱元音 | 六类是教学框架，不是覆盖所有英语词的绝对算法；实际拆分与读音须审核 |
| 11. 词尾变化与基础词素 | 2 | -s/-es 的 /s z ɪz/；-ed 的 /t d ɪd/；-ing、常见复合词；选学 un-/re-/-ful/-less | cats/dogs/buses；jumped/played/wanted；词尾音取决于前面的声音而非只看字母 |
| 12. 综合迁移与阅读 | 2 | 跨规则读词、听写、句子和短故事；已学词到新词迁移；个人易错点回顾 | 小故事贯穿前面模块，本模块集中整合，不等到最后才阅读 |
| 合计 | 48 | 由易到难，同时允许按能力跳转 | 不按完成页点击次数判定掌握 |

### 4.1 横向贯穿的内容

- **音素意识**：词首/中/尾音、口头合音、分音、增加/删除/替换音素，如 cat → sat、smile 去掉 /s/ → mile。先从两三个音开始。
- **词族归纳**：-at、-an、-ap、-et、-en、-ig、-in、-op、-ot、-ug 等，帮助比较；不能只背词尾而跳过逐音合成。
- **易混听辨**：/ɪ/–/i/、/ɛ/–/æ/、/ʊ/–/u/、/v/–/w/、/l/–/ɹ/、/s/–/θ/；只选在目标口音下确实构成有效对照的词。
- **拼写位置规律**：如 ai/ay、oi/oy、ck、tch 的常见位置，用“通常”并配合例外；不能仅凭规律判所有拼写。
- **拼写变化**：run → running、make → making、baby → babies 等放进阶扩展，不和首次认识相应音的课程同时堆叠。
- **口型与发音意识**：简短的嘴唇、舌位、清浊提示，不承诺仅靠看动画就能纠正发音；优先解决影响理解的问题。
- **可解码高频词**：如 in、it、can，按已有规则拼读；the、said、was、one 等分析可解码部分与特殊部分，不一律整词死记。
- **词义与语境**：具体常用词优先；不为凑规则加入罕见词、成人语境或不适合儿童的例词。

## 5. 每课包含什么

建议每课遵循同一学习闭环，按能力允许跳过已掌握部分：

1. **听与复习**：2～3 个已学声音/单词，必要时先解释新例词的词义。
2. **新规律**：1 个主要规律或一组密切相关的对照，清楚说明适用范围。
3. **示范合音**：声音 → 对应字母/字母组 → 合成完整单词；提供可重复播放的独立示范。
4. **带着练**：听辨、合音、分音、选字母、拼写，逐渐减少提示。
5. **独立练**：混入少量已学规律和未背过但可解码的真词，检验迁移。
6. **用起来**：读短句/短故事并回答简单理解题；起步阶段尚不具备解码条件时，以口头活动代替。
7. **小结与复习**：展示首次答题情况、可再练知识点，安排后续复习。

示例：短 a 课，先听辨 /æ/，再用已学 m/s/t/p 等合成 mat、sat、map、tap；读句前另行确认所需词与特殊高频词已经学过。不能因为故事“很短”就认为全部可拼读。

## 6. 训练方式清单

所有训练均支持明确范围、适龄难度、暂停/继续及有帮助的答后解释。

| 方式 | 孩子做什么 | 关键规则 |
| --- | --- | --- |
| 顺序课程 | 按推荐路径学习、继续上次位置 | 能跳到指定模块，进阶有提示但不强锁 |
| 分类/随机词卡 | 按规律学习或打乱已选内容 | 一轮不重复，支持收藏和“还要练” |
| 字母大小写配对 | 找到 A–a 等对应关系 | 与发音题分开，兼顾 b/d/p/q 视觉辨认 |
| 字母名与字母音 | 根据任务分别听名称、听声音 | 不把两类提示混用；音有多种时给定语境 |
| 押韵与词首/词尾音 | 找相同韵脚或指定位置的音 | 初期为纯听觉活动，音频按钮不提前显示词形 |
| 听音选字母组 | 为声音选择已学的字母或组合 | 同音多拼时加位置/词语语境，不制造多个正确答案 |
| 听词选词/图 | 听完整单词后选对应词或明确图片 | 图片不可歧义；文字选择与词义选择统计分开 |
| 看词选读音 | 听编号选项，选符合词形的读音 | 选项不得显示正确词的字幕；全部为美音 |
| 合音成词 | 听分解音，合起来选出单词 | 不用字母名称代替音素 |
| 分音盒 | 把每个音放进一个位置 | ship 是 3 个音，box 通常是 4 个音，不能按字母数固定盒子 |
| 字母块拼词 | 听词后选择字母/字母组组成单词 | 可拖拽也可点选，支持键盘；可按教学目标切换字母块或字母组块 |
| 词链变换 | 每步改变一个音或拼写部分 | 明确是“换一个音”还是“换一个字母”，二者不能混称 |
| 最小对立听辨 | 区分 ship/sheep 等 | 相同录制条件，避免用音量、说话人等泄露答案 |
| 规律归类 | 给词按短/长元音或组合音归组 | 同一字母组的不同读音分清语境 |
| 听音补全/听写 | 补缺字母组，再到完整拼词 | 给出可确定目标的语境；按规则和拼写位置解释错误 |
| 特殊高频词 | 找出可拼部分与特别记忆部分 | 不误称所有高频词都是不规则词 |
| 音节拼接 | 分段读出双音节词、确定重音 | 采用审核后的教学分段，不随机切词 |
| 可拼读句子/故事 | 先尝试读，再听整句/全文，回答理解题 | 允许点词求助，但求助后不计为无提示独立读出 |
| 跟读与自主朗读 | 听示范、停顿、自己读 | 默认不录音、不自动打分，自评不是客观发音分数 |
| 综合闯关 | 5/10/20 题混合复习 | 范围不足时按实际数量出题，不靠重复凑数 |
| 错题与间隔复习 | 按错误规律重新练习 | 同时复习原题和同规律新题，不只背原答案 |
| 收藏与家长摘要 | 集中回顾难词、查看薄弱点 | 只展示实际数据，不推断智力或学习障碍 |

默认不使用无意义伪词；如未来增加，只用于检验解码、清楚标记“练习词，没有词义”，不进入词汇收藏和常用词统计，也不采用发音有歧义的形式。

## 7. 原创训练样例

以下是用于确认覆盖方式的文字样题，不代表音频和最终题库已就绪。音标仅用于审核说明；真正的听音题答题前不展示括号中的答案文字。

| 编号 | 知识点/题型 | 题目与候选内容 | 答案与解释 |
| --- | --- | --- | --- |
| 01 | 字母名称 | 听字母名 /bi/，选 B / D / P | B；名称不等于 /b/ |
| 02 | 字母音 | 听 /m/，选 m / s / t | m；此题不读字母名 em |
| 03 | 口头合音 | 听 /s/ /ʌ/ /n/，选对应音频 sun / sit / map | sun；初期可只用音频选项 |
| 04 | 短 a | 听 cat，选 cat / cut / cot | cat；比较中间元音 |
| 05 | 短 e | 听 bed，选 bad / bed / bid | bed；目标为 /ɛ/ |
| 06 | 短 i | 听 pig，选 peg / pig / pug | pig；目标为 /ɪ/ |
| 07 | 短 o | 听 hot，选 hat / hot / hut | hot；按选定的美音 /ɑ/ 示范 |
| 08 | 短 u | 听 cup，选 cap / cop / cup | cup；目标为 /ʌ/ |
| 09 | 音素分解 | ship 听起来有几个音？2 / 3 / 4 | 3：/ʃ/ /ɪ/ /p/，sh 对应一个音 |
| 10 | 辅音连缀 | 听 stop，拼入 s、t、o、p | 保留 /s/ 与 /t/，不在中间加元音 |
| 11 | 辅音组合 | 听 chin，选 chin / shin / thin | chin；ch 在本词读 /tʃ/ |
| 12 | th 两种读音 | 将 thin、bath、this、that 按 th 的声音分组 | thin/bath 为 /θ/；this/that 为 /ð/ |
| 13 | ck 拼写 | 听 duck，完成 du__；选 ck / sh / th | ck；这个词的词尾为 /k/ |
| 14 | 长短元音 | 分别听 cap、cape，匹配词形 | cap 的 a 为 /æ/，cape 的 a 为 /eɪ/ |
| 15 | 元音组合 | 听 rain，选 rain / run / ran | rain；ai 在本词为 /eɪ/ |
| 16 | 分音与字母组 | boat 的分音盒放 b / oa / t | 3 个音，oa 为一个元音音素 |
| 17 | 同音多拼 | 显示“下雨”的词义，听 rain，拼写目标词 | rain；不能把 rain/rein 当作仅凭音频即可分辨的选项 |
| 18 | r 控制元音 | 听 bird，选 bird / bed / bad | bird；ir 在本词为 /ɝ/ |
| 19 | oo 两音 | 将 book、look、moon、food 分类 | book/look 为 /ʊ/；moon/food 为 /u/ |
| 20 | oi/oy | 听 toy，选 toy / tie / day | toy；oy 在本词为 /ɔɪ/ |
| 21 | 多读音组合 | 将 snow、grow、cow、now 按 ow 读音分类 | 前两词 /oʊ/，后两词 /aʊ/ |
| 22 | 易混听辨 | 听 ship，选 ship / sheep | ship；区分 /ɪ/ 与 /i/，不是只比长短 |
| 23 | 词链变换 | cat → sat → sit，每步哪个位置的声音变了？ | 第一步词首，第二步中间元音 |
| 24 | x 与音素数 | box 有几个音？3 / 4 / 5 | 通常 4：/b/ /ɑ/ /k/ /s/；x 对应两个音 |
| 25 | 特殊高频词 | said 中哪部分不能按刚学过的 ai → /eɪ/ 直接读？ | ai；said 中该部分读 /ɛ/，s/d 仍可用已有知识 |
| 26 | 双音节 | 合成 sun + set，再听完整单词 | sunset；是复合词示例，不据此推导所有音节切分 |
| 27 | -s/-es | 将 cats、dogs、buses 按词尾声音分类 | /s/、/z/、/ɪz/ |
| 28 | -ed | 将 jumped、played、wanted 按词尾声音分类 | /t/、/d/、/ɪd/；不是全部加一拍读 ed |
| 29 | 拼写与意义 | 听 “I can see the sea.”，为“海”选 sea / see | sea；词义或语境决定同音词的拼写 |
| 30 | 解码后理解 | 读 “A cat is on a mat.”，选择猫在哪里 | On a mat；先确认 a/is/on 与相关规则已教 |

### 7.1 分级短文本样例

文本为原创。下列“前置内容”仍需在正式课程逐词标注，不按句长或生词比例直接判为可拼读。

**A. 短元音起步**

> Sam has a cat. The cat is on a mat. Sam can pat the cat.

前置内容：相关辅音与短元音；Sam 作为名字预教；a、the 的常见弱读以及 has、is 中的 /z/ 已示范。理解：Who has a cat? / Where is the cat?

**B. 辅音组合**

> A fish is in a dish. A cat can sniff the fish. Sam can shut the cat in.

前置内容：sh、th、短元音、sn 连缀、双写 ff；a/is/the 与名字 Sam 预教。理解：What is in the dish? / Who can shut the cat in?

**C. 词尾 e**

> Kate has a kite. The kite is red. Kate can run. The kite can rise.

前置内容：a_e、i_e、短元音；Kate 名字预教，rise 中 s 为 /z/，以及 a/the/has/is。理解：What does Kate have? / What color is the kite? 问题可由中文指令或音频呈现，不要求问题本身全部可解码。

**D. 元音组合与 r 控制元音**

> Mark has a toy boat. The boat is in a pool. Mark can see a star on the boat.

前置内容：ar、oy、oa、oo /u/、ee、st 连缀；Mark 名字及相关高频词预教。理解：Where is the boat? / What can Mark see on it?

实际故事应逐步增加连贯情节、因果与趣味性；受控解码不等于堆砌无意义句子。与家长共读的普通绘本可难于当前解码水平，但必须标为“听读/共读”，不能计入独立可拼读测验。

## 8. 题库规模与内容组织

### 8.1 建议完整目标

| 内容 | 建议目标 | 数量口径 |
| --- | ---: | --- |
| 课程 | 12 模块、48 短课 | 每课有目标、先修内容、示范、训练和复习 |
| 常用例词 | 至少 600 个，其中基础约 400、进阶约 200 | 按不同拼写的词条去重；同一个词用于多个规律不重复凑数 |
| 高频词专项 | 约 100 个 | 是例词库的标签子集，不额外累加；分可解码与含特殊部分 |
| 原创客观题 | 至少 960 道，平均每课约 20 道 | 按不同教学目标/题干/目标答案组合统计；仅打乱选项或替换布局不计新题 |
| 可拼读短句 | 至少 120 条 | 按规则分级，逐词检查先修覆盖，不以随机拼句凑数 |
| 原创短文本 | 至少 36 篇 | 起步约 10～25 词，后续约 30～80 词；不强迫最早的字母课配故事 |
| 理解问题 | 每篇 2～3 道 | 先事实信息，后简单顺序/推断；必要时中文提问 |
| 音频 | 所有正式教学和听力题所需音频完整覆盖 | 按字母名/音素/词/句/故事分别建清单，数量随审核后词库确定 |

这里的“完整”指课程主线和常见模式完整，不承诺穷尽英语全部拼写规则、词汇及例外。建议分模块制作并审核，但不把少量示例页当作完整交付。若资源授权或预算影响范围，先更新文档与用户确认，不静默缩水。

### 8.2 每项内容至少要记录什么

- 稳定标识、模块、课次、知识点、先修规则、难度、基础/进阶标签。
- 词形、美式读音、词义、词性、例句；多读音/同音异形/例外标签。
- 字母组切分与音素切分分别存储；两者不必一一对应。
- 题型、题干、正确答案、干扰项、解释、提示，以及音频/图片依赖。
- 文本中已学规则覆盖、需预教词清单；不能只凭“认识了多少词”计算可解码性。
- 内容来源、素材许可、作者/署名、修改记录、审核人/日期和状态。
- 审核状态至少区分草稿、待音频、待审核、可发布；未达标项不能进入正式题池。

这只是数据完整性要求，不是本轮开始实现数据结构或数据库。

## 9. 学习记录、复习与家长查看

- 沿用免登录、本机存储，英语与语文记录分开；新增模块不得覆盖旧记录。
- 保存课次断点、学习范围、收藏、错题、自评、首次作答结果、提示/求助使用情况。
- 区分“看过”“跟读过”“自评会读”“无提示首次答对”，不合并成虚假的统一掌握率。
- 默认每轮 10 题，可改为 5/20 题；跳过单独统计，重试不改写首次作答。
- 建议复习时机为下一次学习、约 3 天后、约 7 天后；仅作为可调整的学习安排，不宣传必然有效的记忆公式。
- 建议掌握参考：同一规律至少两轮、每轮至少 5 个不同有效题、无提示首次正确率均达到 80%；两个学习日有表现后再标记“较稳定”。题量不足显示“证据不足”。
- 以上阈值是可调整的产品规则，不是教育诊断；也不能据此断言口语发音达标。
- 错题可以按规律、听辨、合音、拼写、词义分组；出错后提供少量同规律新题，避免只记题目。
- 家长摘要展示本周练习、待复习知识点和建议练习，不显示排名或制造羞耻感。
- 默认不收集姓名、学校、照片，不启用麦克风，不上传学习行为。
- 本机存储失败时提示并允许临时练习；重置需二次确认，说明清理浏览器可能丢失记录。

## 10. 音频与素材实施前置条件

### 10.1 音频优先级

1. 优先获得有明确授权、可随应用分发的美式教学录音，或者获得授权的美式发音者专门录制。
2. 完整词句可考虑具有合适授权的 en-US 语音服务生成后人工逐条审核；不得默认用户愿意付费。
3. 独立音素、合音示范必须单独验证，不以词句 TTS 能工作推断音素也正确。
4. 尽量统一核心示范者；不同示范者的拓展听力可以后加，但不得导致题目靠声音身份而非发音判题。
5. 审核通过后将音频随静态站点提供或使用明确可控的资源方案；不依赖不稳定外链，也不未经授权抓取词典音频。

### 10.2 每段音频的审核清单

- 来源链接或录制/生成记录、作者/服务、授权条款及版本、允许的用途、署名要求。
- 文本、目标词义/语境、en-US 口音、音素/重音、是否独立音或自然词句。
- 拼写—声音对应正确，无截断、附加元音、错误重音、奇怪停顿或混合口音。
- 音量基本一致，无严重噪声、爆音、长静音；慢速播放后仍可辨认且不变调。
- 文件可解码、播放可取消、手机浏览器经用户操作后可正常播放。
- 两层审核：自动检查格式与覆盖；有美音教学能力的人工核对内容。技术测试不能替代教学审核。

若无法获得合格音源，允许继续编写内容草稿，但不得宣称“美音自然拼读已完成”，也不得用未审音频进入正式练习。

### 10.3 图片、故事与使用权

优先原创文字、原创简单插图或明确许可素材。免费可看不等于可复制、改编或再分发；不能整套搬运商业分级读物、网站练习包、教材截图或歌曲录音。

不默认采购、订阅、开通 API 或上传儿童信息。需要费用、外部服务、云端声音处理时，另行征得用户确认。

## 11. 其他适合三年级的英语小分类

以下是**建议路线，不是本轮默认全部开发**。保持每类目标清晰，与自然拼读共享词库但不重复堆相同卡片。

| 优先级 | 小分类 | 适合三年级的内容 | 与自然拼读的区别 |
| --- | --- | --- | --- |
| 优先补充 | 主题词汇 | 自我与家人、校园文具、颜色数字、身体、动物、食物、衣服、家与房间、玩具、天气季节、时间日期、运动与日常活动 | 核心是“知道词义并会使用”，不是主要按拼写规律分组 |
| 优先补充 | 听力小练习 | 听词选图、听指令做选择、听短句、听 2～4 轮小对话；位置、数量、人物、喜好 | 核心是理解声音中的意思，全部配美音 |
| 优先补充 | 情景口语 | 问候、自我介绍、询问姓名年龄、介绍家人、表达喜好、课堂求助、礼貌请求、简单购物和点餐 | 核心是会在场景中说话；默认角色轮流跟读，不依赖自动评分 |
| 优先补充 | 分级阅读 | 可拼读文本与听读故事分轨；人物地点、顺序、简单因果、预测与复述 | 自然拼读侧重解码，本分类侧重理解、阅读量与兴趣 |
| 下一阶段 | 句型与语法小积木 | I am… / This is… / I have… / I like… / Can you…? / Where is…?；be、代词、a/an、复数、简单介词、问句 | 用具体情境和句子积木教学，不做成人式术语灌输 |
| 下一阶段 | 拼写与书写 | 字母规范书写、大小写、词间空格、句首大写、句号问号、主题词听写、短句整理 | 自然拼读已含基础编码；此处扩展书写习惯、常用词与句子规范 |
| 下一阶段 | 看图表达与小写作 | 补全一句话、描述人或物、给图片写 2～4 句、简单小卡片 | 先口头表达再写，提供适量词句支架 |
| 兴趣拓展 | 韵律儿歌与童谣 | 词汇节奏、重音、押韵、动作指令；以原创或授权内容为主 | 用于兴趣和语感；唱歌中的拉长音不作为标准音素教学样本 |
| 兴趣拓展 | 生活与文化小百科 | 日期时间、日常礼貌、食物、运动、节日常识；儿童适龄内容 | 内容理解与文化常识，避免把美国某种习俗描述成所有英语地区都一样 |
| 需教材信息 | 课内同步 | 按实际教材年级、册次、单元整理词汇、句型与复习 | 必须先明确教材版本，不宣称当前通用课程已匹配所有课标单元 |

推荐建设顺序：**自然拼读 → 主题词汇 → 听力小练习 → 情景口语 → 分级阅读 → 句型与语法小积木/拼写书写 → 看图表达**。这只是开发优先级；日常学习中应让听、说、词义和阅读与自然拼读并行，不必先学完整个拼读课程。

字母认知建议先放自然拼读内部，不再单独开一个重复分类；“每日复习、错题、收藏”属于跨内容工具，而不是新的英语知识分类。

如果所有英语分类都采用美音，可以直接复用本稿的发音、拼写与音频标准；建议默认如此。

## 13. 验收清单

### 13.1 教学内容

- 48 个单元的目标、先修、例词、训练和复习可追溯；基础与进阶明确区分。
- 26 个字母名、大小写及课程实际采用的字母音均有覆盖；不暗示一个字母只有一个音。
- 核心拼读模式、多读音和常见例外齐备；完整词库与课程数量以审核清单核算。
- 不把辅音连缀当作单个音素，不混淆字母数、字母组数和音素数。
- 每道客观题只有一个预期答案，或明确允许多个答案；同音词和多读音词有足够语境。
- 选择题干扰项来自同一合理范围，不靠排版、音量、示范者或题干提示泄露答案。
- 每篇可拼读文本逐词检查先修规则与特殊词；理解题答案可从文本或明确允许的简单推理中得出。
- 所有英语示范符合既定美音口径；没有中文谐音注音、英音替代或错误的“绝对规则”。

### 13.2 功能与体验

- 英语入口和自然拼读可访问；语文功能、已有记录与导航规则不回归。
- 顺序、随机、范围筛选、断点继续、错题、收藏和复习符合定义。
- 每个正式点读项目可播放对应审核音频；失败有提示，不能出现无声却标为正确示范的情况。
- 听音题不提前展示目标词、字幕或答案提示；音频无法播放时允许跳过且不计为知识错误。
- 首次作答、重试、跳过、提示、自评分开统计；不生成未经测量的朗读分数。
- 主要按钮至少约 44×44 像素；键盘、清晰焦点、非拖拽替代、减少动画均可用。
- 无障碍标签不直接泄露测验答案；不适合听觉障碍用户的听辨模式说明限制，提供不计为等价测验的文字学习路径。
- 中文释义与英语文字可读，注意 a/g 字形；正误不只用颜色表达。
- 检查电脑、平板、手机布局及实际可验证浏览器；明确区分模拟测试与真机测试。
