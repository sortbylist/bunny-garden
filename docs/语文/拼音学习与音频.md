# 拼音学习与音频

拼音学习是语文第一阶段的首个主题。课程从 `a → o → e → i → u → ü` 开始，覆盖 63 个基础认读项目、128 个常见单字和 70 个双字词。通过听辨、拼读、配对和规则练习巩固，声母、韵母和整体认读归入学习范围。

「学习」区选择分类和认读内容，从学习卡进入本节练习。「练习」区选择固定练习范围，综合练习面向整个主题。自评认识和客观答题分开记录。收藏、错题和学习记录可在右上角「我的」查看。

## 本地音频

音频随 `public/audio/` 中的静态资源提供。主要来源是 `hugolpz/audio-cmn`，má（二声）采用 Wikimedia Commons 收录的 Yue Tan 真人录音。来源、许可和覆盖清单见 [署名](../../public/audio/ATTRIBUTION.md)、[上游说明](../../public/audio/UPSTREAM-README.md)、[资源清单](../../public/audio/manifest.json)和[替换规则](../../public/audio/overrides.json)。

- 独立 `ong` 录音尚缺。学习卡使用 `dōng` 例音，提示听后半段。独立韵母听辨排除该例音。
- 部分韵母用同音或完整音节示范。声母用教学呼读音对应的音节示范。有些三拼的独立分解音尚缺，仍可听完整音节。
- 13 个双字词使用单字录音串联，界面提示逐字拼读。轻声词采用已有完整录音。
- `npm run audio:download` 补充缺失文件，保留已有文件。`npm run test:audio` 检查浏览器解码和非静音，发音、呼读音与语流变调仍需普通话教师逐项试听。
