# 汉字笔画与结构：实现与验收

## 入口与学习原则

- 「汉字笔画与结构」和「拼音学习」同属语文第一阶段。
- 六个分类均可直接进入。

## 内容范围

| 分类 | 当前内容 |
| --- | --- |
| 认识笔画 | 横、竖、撇、捺、点、提、横折、竖钩、横钩、竖折、撇折、横撇，共 12 种，含方向说明和例字 |
| 汉字笔顺 | 三、十、人、大、小、木、口、日、林、土、王、上、下、天、禾、山、田、目、又，共 19 字；覆盖从上到下、从左到右、先横后竖、先撇后捺、先中间后两边、先外后内和最后封口 |
| 偏旁部首 | 氵、亻、扌、木、艹、讠、口、日、女、土、忄、宀、辶、足、门、囗、钅、纟、犭、饣、虫、鸟、鱼、雨、⺮、贝、衤、礻、疒、心，共 30 项，每项 6 个例字，共 180 个例字；说明偏旁和部首的区别、竹字头的部首写法，以及字义线索的适用边界 |
| 独体字 | 人、大、小、木、日、月、牛、水、火、山、田、土、王、禾、上、下，共 16 字 |
| 左右结构 | 明、林、休、河、语、打、清、晴、情、请、妈、好、姐、坡、桥、枝，共 16 字；显示左右部件关系 |
| 上下结构 | 早、草、苗、尖、尘、星、字、安、李、杏、男、思、音、岩、香、笑，共 16 字；显示上下部件关系 |

共 109 个学习项目和 358 道题。例字自动换行以适应窄屏。题量设置在练习页，拼音辅助在全局学习偏好中设置。

笔顺路径为项目内绘制的 SVG 线条，使用浅色完整字作参照、深色已写笔画、紫色当前笔画和绿色起笔点。支持“下一笔”“上一笔”“从头看”及逐笔跳转；当前笔画有短暂书写动效，可通过学习设置或系统减少动态效果关闭。界面明确标注为线条示意，不是楷书字帖、手写识别或书写评分。

## 练习、记录与奖励

- 专项练习从当前分类抽题，可选最多 10、20、30 题，题量不足时按实际数量出题。综合练习覆盖全部六个分类，同轮题目各不相同、选项随机。新轮优先抽取未出现的题目，抽遍范围后重新循环。
- 题型包含笔画辨认、第一笔及后续各笔、笔画数、偏旁名称、每个例字的部首及三类结构判断。
- 新增可关闭的难词拼音，例如横撇、竖心旁、宝盖头、安宁。保留笔顺主图、步骤和部件展示的清晰字形。设置按主题保存，切换题数立即打开对应题量的练习，切回原题量即可恢复原题目和作答进度。
- 答错后可重试或看答案；首次结果单独记录，重试答对不修改首次正确率。查看答案后显示解释，不算答对。
- 汉字错题与拼音错题分开保存，可从「我的」或练习结果进入。错题在新一轮错题复习中首次独立答对后移出。
- 自评认识、首次答对、独立改错、每日有效练习复用现有星星奖励规则，使用 `hanzi:` 标识去重，不重复发奖。
- 完成一轮后写入现有学习历史，重复点击或刷新不重复记录。
- 状态保存在 `subjects.chinese.stages.chinese-1.topics.hanzi-structure`。主题记录所选分类与学习项目，各分类保存笔顺步骤、自评、错题和专项练习，综合练习保存于主题。切换学科、功能或刷新后均可继续。
- 汉字进度随三科备份和清空。浏览器存储不可用时可临时练习。详见 [本机数据与备份规范](../本机数据与备份规范.md)。

## 自动化验收

- `tests/hanzi.test.mjs` 验证内容覆盖、标识与答案唯一性、笔顺固定序列、专项和综合组题、重试、跳过、独立复习、刷新恢复与奖励去重。
- `tests/chinese-aids.test.mjs`：词组标音、20/30 题恢复、未见题优先、题量不足和辅助设置兼容。
- `tests/browser/hanzi.spec.js`：入口与自由切换、逐笔操作与恢复、自评去重、结构和偏旁展示、完整答题与错题复习、统一历史、个人工具路由、清空确认、存储不可用、键盘和减少动态效果。
- 响应式检查覆盖 1440、820、390、320 像素宽度，检查学习和练习视图的横向溢出。

教学内容采用常见小学基础知识，自动化验证不能替代教师对笔顺示意、字形和教学表述的人工复核；发布前仍建议人工逐项审核。
