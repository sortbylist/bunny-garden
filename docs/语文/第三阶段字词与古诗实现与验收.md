## 字形与读音

形近字先比较偏旁或笔画，再回到词语和完整句子。偏旁仅提供线索，不把字义解释为偏旁的机械推导。笔画辨析覆盖未/末、土/士、人/入、休/体、日/目和鸟/乌等。

同音字覆盖带/戴、在/再、坐/做、进/近、声/生、时/石、园/圆、向/像、课/刻、清/轻。多音字覆盖长、行、乐、重、好、干、空、教、觉、背、得、着，只列适龄的常见用法，不声称穷尽所有义项。

多音字题展示完整词语及对应句子，避免脱离语境猜读音。关闭“拼音辅助”会隐藏 ruby 辅助标注，但保留作为教学内容的读音说明和读音选项。不会给题目中的单个多音字强行套用一个固定读音。

## 古诗积累

二十首诗均含作者、朝代、原文、逐字拼音、适龄简释、关键词和表达任务。注音使用字典本调。合成朗读中的语流和多音字仍需教师试听复核。

“遮住原文试着背”隐藏当前诗的原文和原文注音，可随时重新打开；释义和理解提示仍可阅读。遮文状态按诗保存，刷新可恢复，换诗互不覆盖。它是自我练习，不录音，不自动判断是否背会。

诗题包括接句背诵、词义与画面/情感理解。接句题只显示上句提示，不把缺失的下句同时显示在题干中。

节日卡涵盖春节、元宵、端午、中秋和重阳，日期明确为农历；保留地区习俗差异。寓言为原创适龄改写，包括《守株待兔》《亡羊补牢》《揠苗助长》《画蛇添足》《刻舟求剑》《坐井观天》《狐假虎威》《南辕北辙》《掩耳盗铃》《杯弓蛇影》。每则都有完整经过、词义或寓意提示、两道理解题和联系生活的表达任务。熟语联系生活讲解“熟能生巧”“众人拾柴火焰高”。

20 首诗均提供“听示范朗读”“慢速听一听”“停止朗读”。每次播放包括标题、朝代、作者及完整原诗；慢速为 0.8 倍速并保留音高。默认不自动播放，重复点击会停止前一次播放；换诗、切主题、开始练习、打开弹窗或页面进入后台时停播。加载与播放失败在朗读区显示提示，可重新点击尝试，不计作知识错误。朗读和停止不会发放学习奖励。

语音由 Windows `System.Speech` 的 `Microsoft Huihui Desktop` 离线合成，界面明确标注为合成语音。全部 WAV 文件随静态站点发布，播放不依赖系统语音、不需要用户安装中文语音包，也不向外部语音接口发送文字。清单记录朗读全文、来源及 SHA256。生成命令是 `npm run poetry:audio:generate`，要求 Windows 安装对应语音；生成器对子进程设置 `RemoteSigned`，不修改全局执行策略。

录音的可解码、非静音及播放交互可以自动验证；多音字、节奏、停连与教学示范质量仍需普通话教师逐首试听，不能用技术验证代替。开放表达提供参考和自查提示，不做自动批改；遮文背诵仍不录音、不自动评分。

古诗和文化卡使用稳定的标识保存草稿、遮文、自评和错题。新增内容归入现有五个分类，同时计入该主题徽章和第三阶段奖牌的课程范围。已获奖励保留，未完成进度按扩充后的课程计算。

## 背诵与录音的长期边界

遮文背诵由学习者自评。长期要求见 [项目边界](../README.md#项目边界)。

保留示范朗读、原文与拼音、遮文背诵以及自主练习。录音保存不是本次新增功能，也不是已确定的后续任务；将来若单独确认增加，只考虑可选的本机录制、回听和保存，不转写、不评分、不上传。

不能假定所有电脑都有麦克风。无录音设备、权限被拒绝或录音不可用时，学习、练习、进度和奖励都必须正常使用，不能设置录音前置条件。

## 内容核对

古诗为公版原文，释义、题目、检查提示和寓言改写为项目编写。未声明逐课对齐某一教材版本。

- [中国孔子基金会主办的中华经典吟诵大会青少年组篇目](https://www.chinakongzi.org/zt/ys/ysbd/201709/t20170916_144058.htm)：核对古诗篇名、作者、朝代和原文。
- [中国非物质文化遗产网：元宵](https://www.ihchina.cn/project_details/10126)、[中秋](https://www.ihchina.cn/art/detail/id/14931.html)、[重阳](https://www.ihchina.cn/project_details/10198/)：核对农历日期与常见习俗。
- [故宫博物院：端午节](https://www.dpm.org.cn/lemmas/242938.html)：核对端午节日期及相关习俗。
