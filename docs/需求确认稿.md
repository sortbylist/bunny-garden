# 小学学习乐园：需求确认稿

版本：v0.1  
日期：2026-11-07  
状态：用户已确认按默认方案开始，已进入实现。当前交付与验收记录见《实现与验收.md》；本文件保留原始需求及默认约定。

后续语文分类规划见 [《语文学习分类规划》](语文学习分类规划.md)（2026-11-08）。用户重点确认：**不必学完前一类才开始后一类；古诗积累、朗读、口头表达和简单写作，都可以从一开始穿插进行。**

## 1. 产品目标与边界

面向小学三年级儿童，提供语文、数学、英语三个学科学习入口。以简单、可听、可操作、鼓励性的交互，帮助孩子自主练习。

第一版重点完成“语文 → 拼音学习”，覆盖从基础认读到常见字词拼读的多种练习。三年级使用场景兼顾基础补习、易错辨析与复习，不把所有孩子都视为零基础。

已明确的用户要求：

- 左侧展示语文、数学、英语的图标和名称，点击切换学科。
- 左侧顶部有收起/展开按钮。
- 页面顶部展示当前学科的小功能 tab，点击切换。
- 顶部 tab 按分类展示，使用固定高度的单行导航；分类与目录交互按 2026-11-12 更新后的第 2.2 节执行。
- 视觉风格参考 Bunny Math。
- 拼音学习至少有顺序学习、随机练习；每个拼音均可点击听读音。
- 可补全声母、韵母、简单汉字拼音等训练，内容尽量全面。
- 先确认需求文档，再设计并开发。

建议第一版：数学、英语保留可切换的入口及清晰的待建设页面，具体练习后续补充。此项需要用户确认。

## 2. 导航与交互规则

### 2.1 学科侧栏

- 展开时显示“图标 + 学科名”，收起时保留窄图标栏及展开按钮。
- 当前学科有明确选中状态；图标模式仍提供名称提示及无障碍标签。
- 默认进入“语文 → 拼音学习”，侧栏在桌面端默认展开。
- 记住用户的侧栏偏好，以及各学科上次访问的小功能。
- 手机端建议使用可关闭的抽屉式学科导航，避免挤占练习空间；平板和电脑保留侧栏。

### 2.2 顶部小功能 tab

- 这里的 tab 属于学科小功能，例如语文下的“拼音学习”“识字学习”“古诗学习”；后两项只是未来扩展示例，不代表本期交付。
- 拼音内部的“顺序学习、随机练习”等属于练习方式，在拼音页面内选择，避免与学科小功能混淆。
- 语文按“字词基础、句子运用、阅读与积累”等阶段组织，拼音学习是第一阶段的首个主题。阶段菜单显示已上线的阶段与主题数量，各主题可直接进入。
- 桌面端为“分类下拉 + 本类主题单行横向滚动 + 本类目录”，两侧滚动按钮保留固定位置；主题再多也不换行、不改变头部高度。
- 本类目录浮在内容上方，支持搜索、完整名称、当前项标记与无结果提示；超长目录内部滚动，可按 Escape 或点击外部关闭。
- 760px 及以下使用“分类下拉 + 当前主题下拉”，省去横向主题列表；长标题在入口省略，在目录内完整显示。
- 记住各学科、各分类上次选择的主题。切换或刷新后恢复选择，桌面选中项滚到可见位置，主题保持原顺序；学习操作保留导航位置。
- 拼音内部玩法使用同一套紧凑导航，按“认识拼音、趣味练习、巩固提高”分类；错题本与收藏仍从成长花园或“我的”菜单进入。
- 顶部与拼音玩法的分类入口、分类菜单均带彩色编号标识，按钮按内容收紧留白；主题保留各自图标，所有错题本入口统一使用记事本图标，包括成长花园、“我的”菜单与学习结果页。
- 以上规则取代原“默认十项、展开换行、点击内容自动收起”的约定。
- 切换学习方式不偷偷清除未完成练习；离开时保存进度，返回可继续或主动重新开始。

## 3. 参考风格与儿童使用要求

用户提供的地址：https://binarydevil.github.io/bunny-math/  
检查时该地址跳转至：https://bunnyland.app/

根据页面源码及样式，可确认其视觉特征为浅粉色格纸背景、白色圆角卡片、深紫色描边、粉/紫/薄荷绿/浅黄点缀、大按钮及按压阴影。后续设计参考这些特征，采用适合中文和拼音的字体；当前尚未进行浏览器截图比对或具体界面设计。

- 中文界面，指令短而清楚，例如“听一听”“选一选”“再试一次”。
- 拼音、声调符号清晰，不被装饰字体、裁切或行距遮挡；注意 a、g 等字形的教学可读性。
- 主要触控目标至少约 44 × 44 像素，正文建议不小于 18 像素，核心拼音明显放大。
- 正误反馈同时使用文字、图形和颜色，不只依赖红绿区分。
- 提供键盘操作、清晰焦点及按钮名称；减少动画偏好生效。
- 用温和鼓励代替排名、扣分羞辱和强制倒计时；默认不计时。
- 学习语音与庆祝音效分别控制，关闭音效后仍可听拼音。
- 不要求注册，不放广告，不添加与学习无关的外链入口。

## 4. 拼音内容范围

采用简体中文、普通话和小学常见拼音教学口径。基础顺序明确从 `a → o → e → i → u → ü` 开始，不按英文字母表排序。

### 4.1 基础认读库

| 分类 | 内容 |
| --- | --- |
| 单韵母（6） | a、o、e、i、u、ü |
| 声母（23，按小学常见分类含 y、w） | b、p、m、f、d、t、n、l、g、k、h、j、q、x、zh、ch、sh、r、z、c、s、y、w |
| 复韵母（8） | ai、ei、ui、ao、ou、iu、ie、üe |
| 特殊韵母（1） | er |
| 前鼻韵母（5） | an、en、in、un、ün |
| 后鼻韵母（4） | ang、eng、ing、ong |
| 整体认读音节（16） | zhi、chi、shi、ri、zi、ci、si、yi、wu、yu、ye、yue、yuan、yin、yun、ying |
| 声调 | 一声、二声、三声、四声，以及不标调的轻声 |

以上为常见“23 个声母、24 个韵母、16 个整体认读音节”的入门教学组织方式；正式内容须核对所选教材及拼音规范，不将它表述为全部语音学分类。

### 4.2 拼读和规则库

- 两拼音节、三拼音节，以及声母、介母、韵母如何组成合法音节。
- 声调形状与听辨，标调位置，`iu`、`ui` 标在后一个元音上的规则。
- `ü` 与 j、q、x 相拼时省略两点；与 n、l 相拼时保留两点；`yu` 等形式分开讲解。
- `iou / uei / uen` 在相应拼写环境中的缩写；y、w 的相关拼写规则作为拓展。
- 平翘舌、前后鼻音、n/l、b/p、d/t、j/q/x 等常见易混内容。
- 轻声及“一、不”、连续三声的常见变调作为进阶内容，区分书面标调和实际语流发音。
- 不给声母单独添加四声，不随机生成不合法音节，不把字母名称、声母教学呼读音和完整音节混为一谈。

### 4.3 常见字词题库

- 建议第一版至少 100 个常见单字、50 个双字词，覆盖生活、校园、动物、自然等主题。
- 示例：山 shān、水 shuǐ、火 huǒ、米 mǐ、书 shū、猫 māo；词语按完整语境标注读音。
- 多音字先避开孤立单字题；需要练习时提供词语或句子以确定读音。
- 每道题记录题干、答案、知识点、难度、解析及对应音频，便于检查与扩充。
- 配图只用于不会产生明显歧义的内容；图片素材必须有可用授权。

## 5. 练习方式

以下均为建议纳入第一版的内容，数量较多但可以按“认识拼音 → 练习拼读 → 巩固复习”分组，不在主屏一次堆满入口。

| 方式 | 主要行为与规则 |
| --- | --- |
| 顺序学习（必做） | 从 a、o、e、i、u、ü 起步，随后依次学习声母、其余韵母、整体认读音节；可上一个、下一个、跳转及继续上次进度 |
| 随机练习（必做） | 对所选范围洗牌后逐个学习，每轮内不重复；完成一轮后主动开始新一轮；可选全部或指定分类 |
| 声母学习 | 23 个声母分类认读、点读、示例音节和易混提示 |
| 韵母学习 | 单韵母、复韵母、特殊韵母及鼻韵母分类点读和练习 |
| 整体认读 | 16 个整体认读音节的认读、听辨与例字 |
| 四声与轻声 | 合法示例音节的声调对照、听音选声调；轻声用自然词语说明 |
| 听音选拼音 | 播放音频，从若干候选拼音中选答案；作答前不显示答案提示 |
| 看拼音选读音 | 显示拼音，点击编号音频选项试听并选择匹配项 |
| 拼读组合 | 选择声母和韵母组成合法音节，先听分解，再听完整拼读；逐步加入三拼 |
| 看字选拼音 | 为常见字词选择正确拼音，包含声调；答后可听读音和查看解释 |
| 看拼音选字词 | 根据拼音选择匹配字词；同音候选需有语境，避免出现多个正确答案 |
| 易混专项 | 选择平翘舌、前后鼻音、n/l 等专项集中辨析 |
| 标调与拼写规则 | 选择正确标调或拼写形式，并给出短解释 |
| 拼音配对 | 将拼音与汉字或音频配对，同时提供逐项点击方式，无需必须拖拽 |
| 综合闯关 | 混合已选知识点，每组建议 10 题，可选 5/10/20 题，完成后展示结果 |
| 错题复习 | 收集客观答题中出错的题，支持重做、筛选和掌握后移出 |
| 我的收藏 | 收藏不熟悉的拼音或字词，集中点读和随机复习 |

统一练习规则：

- 认读卡片显示拼音、分类、点读按钮及适量例字；例字以正确的完整音节发音。
- 每个可学习拼音都有可点击的发音入口；测验中会泄露答案的点读入口在提交答案后显示。
- 学习卡片可标记“认识了 / 还要练”，该标记与客观测验正确率分开记录。
- 顺序与随机认读均支持手动翻页，连续播放可作为开关，默认关闭。
- 答题后立即给反馈，出错时允许再试或听解释，不强制快速进入下一题。
- 正确率按首次提交统计，重试不会修改本轮首次作答记录。
- 完成页展示本轮题数、首次答对数、需要复习的知识点，以及继续练习入口。
- 允许跳过；跳过计为未掌握并单独统计，不算答对。

## 6. 语音方案与质量要求

语音是核心交付内容。普通浏览器语音合成直接朗读 `b`、`iu`、`ü` 等字符串，可能读成英文字母或其他错误发音，不能据此判定拼音点读已经完成。

建议方案：

1. 基础拼音使用可合法分发、经人工核对的普通话教学音频，随应用部署或放在可控资源存储中。
2. 声母展示采用一致的小学教学呼读音；在拼读示范中说明其与短促本音的区别。最终以经审核的教学音频为准。
3. 字词及完整音节也需配套审核后的音频；若采用语音服务生成，先核对多音字、声调、轻声与变调，不直接批量生成后视为合格。
4. 浏览器语音合成仅作为经验证的完整字词备用方案；缺少可信拼音音频时明确显示“音频暂不可用”，不能静默用不可靠发音替代。
5. 点击卡片或喇叭播放，支持重复听；快速切换时停止上一段，避免声音叠加。开始播放受浏览器用户交互限制时给出可操作提示。
6. 支持标准播放和慢速播放；慢速须尽量保持音高，不能通过改变音高破坏声调。
7. 提供加载、播放中、失败和重试状态；切换学科或页面后停止播放。

开发前必须落实音频来源、授权及覆盖表。当前尚未收集、下载或审核真实音频；本文件也不宣称题库已经完成。

## 7. 学习记录与数据

- 建议第一版无需账户，使用本机浏览器存储记录，不建设登录和云同步。
- 保存学习位置、已学项目、自评掌握标记、错题、收藏及设置。
- 分别统计“已浏览”“自评认识”“测验表现”，不以点开卡片推断已经掌握。
- 提供重置记录入口，清空前二次确认。
- 说明记录仅保存在当前设备和浏览器；清理浏览器数据可能丢失记录。
- 暂不收集孩子姓名、学校、照片及声音，不接入分析追踪服务。
- 断网情况下仍应能解释资源不可用；完整离线使用、记录导出和跨设备同步作为后续可选扩展。

## 8. 内容来源与审核

- 依据《汉语拼音方案》及选定小学教材口径组织知识点，练习题可原创编写。
- 语料中的知识用于起草，不能代替对教育内容准确性的审核；网站可访问也不等于素材可自由再分发。
- 实施时建立来源清单，记录规范资料、音频和图片的出处、许可、署名要求及审核状态。
- 第一版先使用原创题目及可合法使用的素材，不整套复制商业教辅。
- 检查音节合法性、拼写、声调、多音字语境、选项唯一性、解释和音频是否一致。
- 对尚未核对的内容保留审核状态，不混入正式练习。

## 9. 验收清单

- 三个学科均可切换，选中状态准确；桌面侧栏可展开/收起，窄屏可正常操作。
- 用额外 40 个测试主题验证单行滚动、目录搜索、键盘选择、选中项可见与顺序稳定；测试项不作为正式功能上线。
- 验证分类内选择恢复、刷新恢复、目录浮层不撑高头部，以及 320px 至桌面尺寸的布局与学习操作。
- 顺序学习从 a、o、e、i、u、ü 开始，前后翻页和断点继续正确。
- 随机学习仅在选定范围内抽取，一轮无重复、不漏项；范围不足一组题量时明确提示按实际数量练习。
- 基础认读库各分类数量、内容及对应音频完整；每项发音经人工试听核对，浏览器行为测试不能代替教学审核。
- 带调拼音及 ü 的显示正确，选项没有歧义，不出现非法拼读。
- 练习反馈、跳过、首次作答统计、错题记录和收藏符合规则。
- 刷新后本机记录仍可恢复；存储不可用时提示并允许临时练习。
- 在电脑、平板及手机代表性尺寸检查布局，覆盖 Chrome、Edge、Safari 的主要操作及音频播放行为；报告实际验证范围。
- 没有音频重叠、无法退出的弹层或被遮挡的主要操作按钮。
